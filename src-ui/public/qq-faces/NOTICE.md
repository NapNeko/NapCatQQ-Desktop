QQ face thumbnails come from https://github.com/koishijs/QFace at revision
c96fa14ff894147ac0442dda0fce6a4523e5fcbd. The sync script retains only the
first image frame, scaled to a maximum edge of 64 pixels with a transparent
128-color PNG palette. manifest.json records
the original Git blob hash and each derived thumbnail's SHA-256.

QFace's README attributes all emoji artwork to Tencent and states that the
resources are for learning and exchange, not commercial use:
https://github.com/koishijs/QFace#readme

The QFace project's code is MIT licensed. That code license is not presented
here as a license for Tencent's artwork.
