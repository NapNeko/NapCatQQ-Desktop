「概览」适合在打开软件后先看一眼：有没有实例异常、哪些组件有更新、远端档案是否准备好了。真正的启停、登录和配置仍在对应管理页完成。

![概览汇总实例、主机和近期提醒；截图使用客户端演示数据。](/docs/screenshots/overview-light.png)

## 先看实例，再看 QQ 是否登录

顶部的「个实例运行中」可以进入机器人列表；「台主机」可以进入远端页。主机数量统计的是已保存的档案，不代表每台主机当前都能连接。

当「实例状态」卡片可见时：

1. 看「运行中」「已停止」及「待处置」。这些数量针对协议 Bot，不是应用框架数量。
2. 有待处置项时，读它旁边的原因，例如「进程异常退出」「等待重启」或「运行异常」。
3. 点击该项或「管理实例」，进入机器人列表，找到对应账号。
4. 按问题处理：进程退出先看日志；等待重启先确认保存过什么配置，再选择合适时间重启。
5. 处理后回概览确认状态，再到机器人卡片核对 **QQ 已登录**。进程运行不等于 QQ 在线。

待处置最多展示 6 项，活跃实例最多展示 4 项。账号很多时，应到 [机器人列表](/docs/bots/) 检查全部实例，不能把这个摘要当成完整清单。

## 最近通知：按提醒找到处理入口

「最近通知」汇总启动时的数据整理与迁移提示、组件版本提醒，以及运行中的掉线、异常等事件。列表优先展示严重的提醒，最多展示 8 条，并不保证严格按发生时间排列。

1. 先读通知标题和详情，留意它关联的账号、版本和时间。
2. 有「管理实例」「去升级」等操作时，点击进入对应页；带外部链接的通知也可打开来源页面。
3. 运行问题继续查 [Bot 日志](/docs/tasks-logs/)，升级问题先看 [组件管理](/docs/components/)。
4. 数据目录整理提醒里若给出备份位置，先保留备份，确认数据正常后再处理；不要直接删除仍在排错中需要的文件。

「一切正常」表示当前没有可展示的通知，不是对所有账号、插件和远端服务的实时验证。要确认推送是否成功，应到「设置 → 通知」查看 [投递记录](/docs/settings/)。

## 查看本机协议端版本

NapCat 和 SnowLuma 小卡片展示本机组件版本与可更新状态。点击卡片进入组件页，再核对选中的主机和组件。

准备升级时，先停止受影响的 Bot，查看版本说明，并备份必要数据。远端组件要切换到对应主机查看；概览的本机版本不能代替服务器上的版本检查。

## CPU／内存曲线怎么出现

1. 打开「设置 → 监控」。
2. 开启「主页性能监控」，选择采样间隔，保存设置。
3. 回概览，CPU 和内存曲线会显示在侧列；关闭时，这个位置显示实例状态摘要。
4. 观察到波动时，结合刚才的启动、安装或框架任务排查。需要看某个 Bot 的资源和节点流量，使用 [运行时指标](/docs/bots/)。

主页曲线反映运行 Desktop 的本机情况，不是所选远端服务器的监控图。历史保留、Bot 指标和远端退出后续写的设置见 [监控说明](/docs/settings/) 与 [远端值守](/docs/watch/)。
