「设置」按外观、功能、窗口、终端、运行、网络、监控、通知、日志、数据和关于分组。窗口较窄时，横向滚动标签条可以找到后面的页面。

## 修改设置后先保存

大部分可编辑项共用一个草稿，修改后右上角会显示「未保存」。点击「保存设置」才写入；「撤销」会放弃这份未保存修改，回到已保存的状态。

1. 打开需要的设置页，修改一项。
2. 查看右上角是否出现「未保存」，有校验错误时先处理字段旁的提示。
3. 点击「保存设置」，等待成功提示和「已是最新」状态。
4. 对需要重启 Bot／实例的设置，按页面说明重启后验证。

数据页的导入、导出、迁移和清理是即时操作，终端偏好也直接保存；这些操作不靠右上角的统一保存按钮提交。

## 外观：主题与侧栏

1. 到「外观 → 界面」，点「主题」右侧当前名称，在按主题族分组的卡片中选择；可使用明色、暗色主题或跟随系统的选项。弹层中还能向下滚动查看其他主题。
2. 根据习惯选择「圆角风格」和「侧栏形态」。悬浮为窄图标卡片，经典为贴边可折叠侧栏。
3. 按需显示或隐藏「主页吉祥物」。
4. 保存设置，观察主题和布局变化。编辑草稿时不会预览主题切换。

![外观设置：主题与布局在保存后生效](/docs/screenshots/settings-appearance-light.png)

「动画与体感」可关闭过渡，或调整动画档位和速度。系统的减少动画偏好仍会影响效果。阅读本教程时，文档站右上角的主题按钮只改变网页；Desktop 的主题在软件自己的设置里修改。

## 功能：整理不用的入口

1. 打开「功能」，阅读每项下方的用途和关闭后行为。
2. 关闭不需要的模块或应用框架入口。
3. 保存后检查侧栏及各页入口。

![功能页：按需要保留聊天、终端及应用框架入口](/docs/screenshots/settings-features-light.png)

功能正被现有 Bot、应用实例、远端值守或终端使用时，相关开关可能不可关闭，旁边会说明原因。先处理具体实例，再回来关闭模块。

聊天开关还会控制聊天窗口、后台接收、账号托盘及截图快捷键；已有记录和账号设置保留。只想让某个账号安静一点，优先改 [账号聊天设置](/docs/chat/)，无需关闭整个聊天模块。

## 窗口：关闭按钮、托盘和开机自启

1. 到「窗口 → 关闭与托盘」，设置「点击关闭按钮」为关闭程序或最小化到托盘。
2. 选择托盘后，可设置关窗后保持隐藏、闲置一段时间释放界面，或立即释放界面内存。延迟释放可选择等待时间。
3. 到「启动」按需开启「开机自启」，并选择启动时显示主界面或仅托盘。
4. 保存后测试一次关窗及从托盘恢复。

开机自启在当前 Windows 用户登录后执行，不等同于系统未登录时运行的服务。有本机 Bot 运行时，退出会受到保护提示；按提示处理，不要把最小化到托盘误认为已经退出。

## 运行：登录检查和远端探活

「运行」页包含三组：

- **Bot 与登录**：调整登录检查间隔。已登录时按设置轮询，未登录时固定一秒检查；填写允许范围内的毫秒值。
- **SnowLuma 运行环境**：自动按内置、Node.js 组件、系统 PATH 的优先级选择，也可从检测到的候选中指定。要求为 `^22.13.0 || >=23.4.0`；环境变化后用重新探测入口刷新。
- **远程主机**：开启后台探活并设置间隔。关闭主动探测后，已有失败标记会保留到下次成功连接或手动测试。

远端连接异常时，仍应先到远端页测试 SSH。缩短探活间隔不能修复认证或网络问题。

![运行设置：分别调整登录检查、SnowLuma 环境和远端探活](/docs/screenshots/settings-runtime-light.png)

## 监控：性能和实例历史

### 查看主页 CPU／内存曲线

在「监控 → 概览性能」开启「主页性能监控」，设置采样间隔并保存，再回概览查看。关闭后主页不再显示 CPU／内存曲线。

### 记录 Bot 运行时指标

1. 在「实例运行时指标」开启「启用实例指标」，默认关闭。
2. 选择采样间隔和「历史保留」。默认保留 7 天，最长 90 天；历史趋势以不低于一分钟的粒度保存。
3. 保存后，**重启被观测的 Bot**，再查看运行时数据。

远端装有 ncd-watch 时，Desktop 退出后仍可继续记录历史；配置方法见 [远端值守](/docs/watch/)。

![监控设置：性能曲线与实例指标各自开启，保存后按提示重启 Bot](/docs/screenshots/settings-monitoring-light.png)

### 清理结束的任务条目

「监控 → 任务队列」可配置自动清理已完成、失败或取消条目的等待时间。关闭自动清理则保留到重启应用。需要留存错误时，先复制日志，再清理条目。

## 通知：先开事件，再配渠道

### 应用内提示条多久消失

这是软件内操作结果条的显示规则，与 QQ 消息和 Windows 桌面通知分别设置。

1. 到「通知 → 应用内提示条」。
2. 分别为「说明」「成功」「警告」开启自动关闭，并调整出现的时长滑块。需要留着读完的类型可以关闭自动消失。
3. 保存设置，再做一次普通保存或检查操作，观察提示条是否按预期保留。

错误提示需要手动关闭。先读完错误并复制需要的信息，再点关闭；把普通提示时长改短不会让错误自动消失。

### 本机桌面通知

1. 到「通知 → 桌面通知」，按需启用「Bot 掉线」「Bot 异常退出」「被踢下线」。
2. 需要掉线提醒时，再到对应 Bot 的高级设置开启「掉线时发送通知」，NapCat 和 SnowLuma 都需要。
3. 保存设置。主窗口隐藏或进入轻量模式时仍会提醒。

「Bot 掉线」开关也控制该事件的 Webhook、邮件与 OneBot 投递。只填渠道、没开事件，无法收到预期掉线通知。

![通知设置：先开启事件，再向下配置通知渠道及投递行为](/docs/screenshots/settings-notifications-light.png)

### 添加 Webhook

1. 开启「Webhook 推送 → 启用 Webhook」，点击添加。
2. 填可识别的名称和服务提供的地址，按对方接口要求选择 GET／POST 及消息内容。
3. 检查通道已启用且不显示「缺地址」，保存设置。
4. 使用页面提供的测试入口，核对接收端是否收到，并查看投递记录。

可以配置多个通道。关闭总开关会保留已填通道。消息体、参数格式以接收服务的接口文档为准；不要把别家服务的模板原样套进来。

### 编辑 Webhook 消息模板

1. 在通道配置里选择与你的接收服务匹配的模板，例如 Server酱、钉钉、飞书、Discord 或 Bark。
2. 在「消息内容」填标题、正文等该服务支持的字段。点「昵称」「QQ」「状态」「时间」按钮，可插入 `{nickname}`、`{uin}`、`{event}`、`{time}`，发送时再替换成当前事件信息。
3. 查看右侧「原始 JSON」，它与表单实时同步。自定义接口可直接编辑 JSON；先把状态改到「合法」，再测试接收服务是否接受这份结构。
4. 改错可用 `Ctrl+Z` 撤销、`Ctrl+Y` 重做。点「发送测试」检查真实投递结果，再保存通道及全局设置。

JSON 语法合法只代表能解析，字段是否满足接收服务仍需看测试结果。Bark 的分组等服务专有字段，按当前模板填写。

### 配置邮件

1. 开启邮件通知，打开配置。
2. 选择常用邮箱预设，或手动填发件邮箱、收件邮箱、SMTP 服务器、端口和连接加密。
3. 填服务商提供的 SMTP 授权码，按邮箱要求启用 SMTP。
4. 保存并测试，检查收件箱和垃圾邮件，再看投递错误。

SMTP 授权码不一定是网页登录密码。连接失败先核对服务商说明、端口与 SSL／TLS 组合，再检查网络。

### 配置 OneBot 通知与重登二维码

1. 开启 OneBot 通知，选择可用的发送方 Bot；缺少所需 HTTP 能力时，按界面入口配置。
2. 在接收目标中选择私聊或群聊，填写真实接收 QQ 号／群号；多个目标按输入框规则添加。
3. 检查消息模板，保存并测试。
4. 需要远端掉线后发送重登二维码时，开启对应选项，填写接收二维码的管理员 QQ，并按 [值守指南](/docs/watch/)完成同机发送方和远端配置。

本机掉线由本机发送方处理，远端由该机 ncd-watch 处理，不跨服务器调用 OneBot。发送方自身也要能运行和发消息，不能依赖已掉线的账号提醒自己。

### 防抖与投递记录

「投递行为」可开启上线恢复通知，设置掉线防抖秒数和历史条数上限。防抖为同一 Bot 在设定时间内只投递一次，填 `0` 关闭；恢复通知默认关闭。

点「查看记录」检查各渠道结果。投递记录只保存在当前进程内存中，重启会清空，历史上限 `0` 表示不记录。测试成功后，也要核对 Bot 的事件开关与真实远端运行条件。

## 网络、日志与数据

- 下载慢、代理或镜像配置：看 [网络与下载线路](/docs/network/)。Desktop 的设置不自动接管所有远端包管理器与框架网络。
- 查看 Desktop 自身错误：看 [任务与日志](/docs/tasks-logs/)。日志页的复制只复制当前可见内容。
- 导入／导出配置、迁移数据、清理下载缓存：看 [备份与数据维护](/docs/backup/)。先弄清备份范围，再操作。
- 字号、shell、文件栏与常用命令：看 [终端](/docs/terminal/)。

## 关于：查看版本、更新和重开入门引导

在「关于」查看当前版本、项目和许可信息。点击检查更新，发现版本后可按页面入口安装；更新会短暂退出应用，完成后自动重开，进度见任务队列。更新前保存正在编辑的配置，并完成必要备份。

不记得各模块入口时，可从关于页重开入门引导。下载发布包时，Desktop 版本与 `watch-v` 远端组件版本分别核对。
