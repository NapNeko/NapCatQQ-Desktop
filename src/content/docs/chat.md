聊天直接使用已经登录的 Bot 账号，不需要先安装应用端。先在「机器人」确认 QQ 在线，再打开「聊天」。本页截图使用软件自带的浏览器演示数据，真实传输与权限以你的协议端为准。

## 选账号，发第一条消息

1. 打开侧栏「聊天」。如果找不到入口，到「设置 → 功能」开启聊天并保存。
2. 从左下角选择账号，进入账号设置，确认「用于聊天」已开启。
3. 在「联系人」里选自己的测试好友或测试群，也可以从最近会话进入。好友可按 QQ 原有分组筛选，群聊在群消息盒子中。
4. 输入一条容易辨认的文字，例如 `Desktop 聊天测试`，发送后检查消息状态，并在对方客户端确认收到。
5. 让对方回复一句，确认当前窗口能实时收到。发送和接收都成功，才算完成验证。

![聊天工作区：先选账号，再从联系人或最近会话进入](/docs/screenshots/chat-light.png)

不同 Bot 的联系人、会话、消息和草稿各自保存。发消息前看清当前账号和会话标题，尤其是在多个账号之间切换时。

## 回复、撤回和转发

在消息上打开右键菜单，可按消息类型使用回复、复制、`@`、撤回或转发。协议端能力、账号身份和消息条件会影响可用操作；菜单置灰时，先检查权限和协议端版本。

发送失败时，先读消息旁的失败原因，再决定重试。不要连续点击发送；网络恢复后可能造成重复消息。发送任务提供取消入口时可以取消。

### 一次转发多条消息

1. 从消息右键菜单进入多选，勾选要发出的消息，底部会显示已选数量，一次最多 100 条。
2. 点「转发」，选择「合并转发」或「逐条转发」。前者生成聊天记录卡片，后者依次发出各条消息。
3. 在「搜索联系人或会话」中找目标，检查待转发预览和接收人，再确认发送。
4. 观察进度和结果。结果不确定时，先到目标会话核对，避免重复发送；不再转发可取消多选。

已撤回、没有有效消息 ID、尚未成功发送等消息可能不能转发。想提及群成员时，也可右键对方头像使用「提及」；「拍一拍」需要账号连接正常和协议端支持。

「重复发送」适合把支持的文字、图片等消息再发到当前会话，操作前看清目标。发送失败后的「重新发送」则用于重试失败任务，先确认失败原因与是否已经送达。

### 看群名片与管理成员

1. 在群资料里点「查看群成员」，用名片、昵称或 QQ 号搜索；也可右键消息头像点「查看群名片」。
2. 选中成员查看身份、头衔、入群时间等协议端提供的信息，按需复制 QQ 号或发起私聊。
3. 有管理权限时，可选择「禁言」「解除禁言」或「移出群」。禁言先选时长，再核对成员 QQ 与群名后确认。
4. 操作完成看结果；权限还在读取时先等待，失败或结果不明时先刷新核对，不要连续提交。

普通成员不会看到可执行的管理操作。管理员只能管理普通成员，群主可管理管理员与普通成员，不能对自己执行这些动作；实际执行仍以 QQ 和协议端权限为准。

## 发图片和文件

1. 使用输入框工具栏的附件入口，或把图片、文件拖入／粘贴到输入框。
2. 检查待发送附件，一次最多添加 8 个。删掉选错的文件，再发送。
3. 等待发送结果。失败时记录错误原因，先尝试一个小文件，区分附件本身问题与账号连接问题。

点击收到的图片可以查看大图。视频、Markdown、合并转发记录等按消息类型显示；图片还没加载好时会显示占位。不要因为占位尚未消失就判断消息为空。

图片查看器可用滚轮缩放、拖动查看细节，底部还可选「原始尺寸」「适应窗口」「适应宽度」及重置。看长图时先试适应宽度；放大后找不到内容就用适应窗口还原。

输入框的表情入口包含 QQ 表情与收藏表情，可按分类浏览、搜索名称或收藏注释，再点击插入。列表没刷新时使用对应的更新入口；收藏内容需要账号和协议端能够读取。

语音支持播放／暂停、拖动进度、查看时长、音量和倍速。第一次播放会先加载；失败后可重试。协议端支持时可转文字。

## 查聊天记录

1. 从左侧「消息／联系人」标签旁点「搜索聊天记录」，可以直接查本账号；查当前会话时也可按 `Ctrl+F`。
2. 在搜索范围中选择当前会话或本账号已保存记录。没有打开会话时，当前会话范围不可选。
3. 输入关键词。需要找附件时，切换「图片/视频」「表情」「文件」「链接」分类，再按发送者和日期缩小范围。
4. 点击结果返回对应会话和消息位置，核对上下文。没搜到时先放宽日期与类型，不要立即判断消息从未出现。

搜索依赖本机已经保存的记录，不会自动拉取账号全部云端历史。近期记录有条数和容量上限；它适合回查，不是完整聊天备份。草稿在退出程序后清掉，聊天消息也不随配置 ZIP 导出。

需要防撤回时，在账号设置中按需开启，默认关闭。它只能保留本机已经收到的内容，不能找回未收到的消息。

### 整理会话，不删除记录

在会话上右键，可以置顶／取消置顶、标为已读或隐藏会话。群聊还可设置「本地免打扰」。隐藏会话不会退出群，也不会把本机已保存的聊天档案删掉；隐藏群聊同时会让它在本地保持安静。

需要找回时，从「联系人」重新打开，或在本账号记录里搜到旧消息后点击结果。左侧的「只看未读会话」与关键词都会影响列表；会话突然少了，先清除这些筛选。`Ctrl+K` 可直接聚焦会话／联系人搜索。

聊天档案会在重开程序后恢复已保存会话、置顶等状态，但运行游标与草稿不跨启动恢复，历史媒体也不保证永久可用。看到聊天记录异常提示时，用提示中的重试入口，先保留错误信息再继续排查。

## 浏览和下载群文件

1. 进入群聊，打开群文件入口。
2. 浏览目录或搜索文件，核对名称和大小后下载。
3. 上传文件时选对目标目录，观察传输进度。
4. 有权限且协议端支持时，可以新建目录、重命名、移动、删除及查看容量。删除前核对对象。

![群文件面板：目录、文件和传输操作集中显示](/docs/screenshots/chat-group-files-light.png)

好友和群消息里的文件卡片也可以下载。Desktop 会优先向协议端取新链接，旧版本不支持时尝试消息自带链接；过期文件仍需发送者重新发送。

传输任务支持进度和取消，关闭群文件面板不会停止已开始的传输。不支持或没有权限的操作会置灰；协议端返回的具体错误可到 [调试台](/docs/debugging/)进一步检查。

## 框选截图

1. 在聊天输入框点截图，或使用默认快捷键 `Ctrl+Alt+S`，打开 Windows 原生截图工具。
2. 拖动框选区域；也可单击窗口选取窗口，或按 `Space` 选当前屏幕。用「调整选区」检查边界，避免把旁边内容截进去。
3. 在工具条选标注工具，设置颜色和粗细后操作。文字工具在选区中输入说明，编号适合给步骤排序；马赛克需拖动框选遮挡区域。
4. 检查结果，使用下表对应的完成方式。加入聊天只进入草稿，仍需回聊天窗口确认接收人后发送。

| 工具／动作 | 快捷键与用途 |
| --- | --- |
| 调整选区 | `V`，重新调整截图范围 |
| 矩形、椭圆、箭头 | `R`、`E`、`A`，圈出按钮或指出位置 |
| 画笔、文字、编号 | `P`、`T`、`N`，自由标注、补充说明或标步骤 |
| 马赛克 | `M`，拖动覆盖需要遮挡的区域 |
| 撤销、重做 | `Ctrl+Z`、`Ctrl+Y`；也可用 `Ctrl+Shift+Z` 重做 |
| 复制 | `Ctrl+C`，结束截图并复制到剪贴板，方便贴到其他程序 |
| 另存为 | `Ctrl+S`，选择位置保存 PNG 图片 |
| 完成／加入聊天 | `Enter`，完成并复制；开启「截图后添加到聊天框」时还会加入草稿 |
| 取消 | `Esc`，放弃本次截图 |

截图按钮旁可打开设置：修改快捷键，选择全局响应或只在程序有焦点时响应，也可设置截图时隐藏聊天窗口。关闭「截图后添加到聊天框」后仍可复制和保存，但不会插入附件或拉起聊天窗口。

全局快捷键在未打开聊天页时也能用。截图窗口被其他窗口挡住时，再按一次快捷键可召回当前截图。

修改快捷键时，点当前组合键，等出现「按下组合键」后按新的按键。使用 `Ctrl` 或 `Alt` 加字母、数字或 `F1–F12`，`Esc` 取消录制；若提示注册冲突，换一个组合再试。「恢复默认」会重置截图偏好。

## 滚动长截图

1. 先框选滚动内容区域，至少为 `32 × 96` 像素。尽量把固定标题和工具栏留在框外；先不要添加标注，已有标注时需全部撤销后才能进入长截图。
2. 点「滚动长截图」或按 `L`，在框选区域内手动滚动。可以先向下，也可以向上补充，预览会向两端扩展。
3. 每次保留一部分上一屏内容作为重叠，不要直接跳到很远的位置。出现「重叠不足，请往回滚一点」时，回滚到能和预览衔接的位置，再小幅滚动。
4. 要停下来检查时点「暂停采集」；点「继续采集」恢复。拼错了用「撤销上一段」或 `Ctrl+Z`，回到上一屏后再继续。
5. 检查文字、接缝、头尾与遗漏，再选择复制、另存为或加入聊天。提示到达长度上限时，完成这一张，再分段截下一张。

截图覆盖的是屏幕上实际可见的内容。发送前留意旁边的账号、群名、密钥或其他窗口，避免把无关内容一并发出。

## 独立聊天窗口

1. 在当前账号点「聊天设置」，滚到「窗口」。
2. 点「在独立窗口打开」。当前会话和草稿会随窗口交接，打开后先确认账号与会话，再继续输入。
3. 需要回到 Desktop 主界面内聊天时，在独立窗口同一位置点「嵌回主窗口」。

窗口交接保留的是当前运行中的视图和草稿，不是退出应用后的草稿备份。

## 后台接收、群免打扰与头像托盘

1. 打开对应账号的「聊天设置」，先开启「用于聊天」。关闭此项会同时停止这个账号的后台接收与托盘提醒。
2. 按需开启「后台接收消息」和「托盘图标」，两项默认关闭。账号设置直接生效，不需要去全局设置另点保存。
3. 在「托盘提醒」选「红点」「头像闪烁」或「不提醒」。让测试好友发一条消息，悬停头像托盘看未读会话，再点击进入对应会话。
4. 对不想提醒的群，在会话右键菜单开启「本地免打扰」。恢复时可在聊天设置展开「本地免打扰群聊」，点「恢复提醒」。

「免打扰状态未知的群」可选「保持安静」或「仍然提醒」。NapCat 能读取的 QQ 免打扰群不会提醒；SnowLuma 不提供这项 QQ 状态，按未知状态的策略处理。关闭本地免打扰不会修改 QQ 自身的免打扰设置。

如果完全不用聊天，在「设置 → 功能」关闭聊天并保存。聊天窗口、后台接收、账号托盘和截图快捷键会一起停止，已有记录和账号设置仍保留。仅关闭窗口不等于关闭所有后台聊天能力。

## 遇到问题先查哪里

| 现象 | 按这个顺序检查 |
| --- | --- |
| 没有可选账号 | Bot 已创建 → 进程运行 → QQ 已登录 → 允许用于聊天 |
| 发得出，收不到 | 账号连接状态 → 事件接收能力 → Bot 日志；必要时在调试台看事件 |
| 媒体始终加载失败 | 协议端版本 → 链接是否过期 → 当前网络；先测试新发的一张小图片 |
| 群文件操作置灰 | 当前账号权限 → 协议端是否支持，不要用刷新代替权限检查 |
| 截图快捷键没反应 | 聊天功能开关 → 快捷键作用范围 → 是否冲突；先试输入框按钮 |
