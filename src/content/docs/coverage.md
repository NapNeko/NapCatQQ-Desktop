这份手册按使用任务组织，涵盖客户端安装、QQ 登录、应用端对接、聊天、远端部署和日常维护。文中的功能和限制对照了 `main` 分支的用户指南与界面实现。

## 覆盖了哪些内容

常规教程的核对基线是 `main` 分支的提交 `85cd7f40739d38a36c40d9d48ff5b390a2056cff`（3.5.2）。在原有 121 项用户任务基础上，新增了 8 项 MCP 任务，共 129 项。MCP 三篇文档对照新版开发实现，已在各页注明版本边界；以安装版本返回的 `tools/list` 和 `get_security_policy` 为准，不将开发功能视为 3.5.2 已发能力。只提页面名称、没有具体操作的，不计为覆盖。

仓库中的 `scripts/docs-coverage.json` 记录了每项任务对应的 `main` 源文件、文档和检查关键词。修改文档后运行 `pnpm check:docs`，可以检查失效链接和部分遗漏；操作步骤是否清楚、是否符合软件行为，仍需对照源码和界面复核。

上游插件参数、OneBot API 和框架内部实现由各自的项目维护。本手册说明 Desktop 的操作，以及 NCD MCP 工具的参数、错误和权限边界；上游动作的具体参数可通过 `describe_action` 或上游文档查询。

## 截图与演示

有 12 篇教程带交互演示，支持暂停、接手操作、重置和放大。演示中的安装、网络测试、OneBot 调用和聊天消息均为模拟。备份教程只演示缓存扫描与清理，ZIP 导入导出需要在客户端中操作。

截图来自项目自带的浏览器演示界面，使用示例账号和数据，包含明暗两套主题。Windows 原生截图选区、系统托盘和安装程序对话框目前只有文字步骤，没有配图。

QQ 登录、SSH 连接、文件传输和模型请求需要使用自己的账号、主机和服务验证。

## 发现文档和界面对不上

请记录 Desktop、协议端或框架的版本，以及主机和部署方式。按照 [排错指南](/docs/troubleshooting/) 的模板写明操作入口、步骤、预期和实际结果。附图前请遮盖密码、Token、私钥和私人消息。
