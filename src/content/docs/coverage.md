## 框架与上游资料的分工

[应用框架指南](/docs/frameworks/) 分别说明七种框架的操作。MaiBot 的表达学习、按会话追加提示词、分时段发言规则和 MCP 接入也有具体示例，并给出保存后应检查的状态。

上游插件的全部参数、每个 OneBot API 和框架内部实现由对应项目维护。本手册介绍在 Desktop 中安装、配置、调用与排错的流程；插件专属参数和模型服务限制，应继续查阅其自身文档。

## 截图与实际操作的边界

截图来自项目自带的浏览器演示界面，使用示例账号和数据，提供明色、暗色对照。Windows 原生截图选区、系统托盘及安装器对话框需要在 Windows 中采集；本手册保留了操作步骤，不使用仿制窗口替代实拍。

教程中的 QQ 登录、SSH 连接、文件传输及模型请求，需要你用自己的账号、主机和服务完成验证。文档覆盖率表示任务已有说明，不代表这些外部环境已在本次编写中逐一执行成功。

## 发现文档与界面不一致

先记录 Desktop、协议端或框架版本，以及所在的主机和部署方式，再按 [排错指南](/docs/troubleshooting/) 提供入口、步骤、预期结果与实际结果。附图前隐藏密码、Token、私钥及私人消息。

结构与教程呈现参考了 [GraiaX 文档](https://graiax.cn/) 的准备条件、连续示例和逐步说明方式；本手册的功能事实以本项目 `main` 为依据。
