Desktop 里内置了终端，查环境、跑命令、改文件都不用再另开窗口。从 Bot、应用实例或者远端主机打开终端时，先看一眼标题里写的主机和目录。同一条命令，在本机、远端和容器里跑，动的是完全不同的文件。

本机终端需要 Windows 10 1809 / Server 2019 或更新的系统（要用到 ConPTY）。找不到终端入口的话，到「设置 → 功能」看看它是不是被关掉了。

## 打开并确认目标

1. 点标题栏的终端按钮，或者按 `Ctrl+反引号` 展开终端面板。反引号一般在键盘数字 `1` 的左边。
2. 用标签旁边的「+」选一个目标，也可以直接从 Bot、应用实例或远端卡片上打开。
3. 看标题里的主机和当前目录。本机 PowerShell 可以输入 `Get-Location`，Linux 远端输入 `pwd`，确认一下自己在哪。
4. 等命令跑完、提示符重新出现，再输下一条。

![终端面板：在执行命令前核对目标和目录](/docs/screenshots/terminal-light.png)

`Ctrl+反引号` 只是把面板收起来，会话还在后台开着。想真正关掉会话，用标签上的关闭按钮。里面还有命令在跑的话，先想好要不要中断它。

## 多会话和分屏

在标签上右键，可以改名、复制出一个同样的会话，或者选「左右分屏」「上下分屏」。一个标签最多分两格，比如一边盯着日志，一边查环境。点了哪一格，键盘输入就进哪一格。

双击标签也能改名。后台标签上会冒出小点提醒你有动静：普通输出是灰点，命令成功是绿点，失败是红点。会话退出或者断线了，标题会变淡。不过小点只是提醒，具体出了什么事，还是要切过去看输出。

目标支持的话，右键菜单里还能打开外部终端，或者把输出保存下来。

## 复制、粘贴与搜索

- `Ctrl+C`：选中了文本就是复制，没选中就是中断当前在跑的程序。
- `Ctrl+V` 或 `Shift+Insert`：粘贴。粘贴多行文本时可能会逐行执行，所以会先弹确认框，看清楚再点「粘贴」。
- `Ctrl+Shift+F`：在输出里搜索，找 `error`、端口号或者某个依赖名时特别有用。
- `Ctrl+↑` / `Ctrl+↓`：跳到上一条／下一条命令。
- `Ctrl+点击链接`：用浏览器打开。
- `Ctrl+滚轮`、`Ctrl+=`、`Ctrl+-`：调字号，`Ctrl+0` 还原。

右键的行为可以在「设置 → 终端」里改，可以改成弹出菜单，也可以改成「有选中就复制，没有就粘贴」。

## 常用命令

1. 打开终端里的常用命令菜单。
2. 从框架预置的命令、自己保存的命令或者最近用过的命令里挑，也可以搜索。
3. 选中以后，命令只会填进输入行，不会立即执行。核对一下目标、路径和参数，再按回车。
4. 想添加自己的命令，填上命令和名称（名称可以不填），比如给一条只读检查的命令起名叫「看当前目录」。

最近命令是按终端目标分开记录的。密码、token、一次性验证码这类东西，别存成常用命令。

## 文件栏

1. 在当前终端格子的顶部点「文件栏」。本机终端显示的是本机目录，远端终端显示的是那台远端主机的目录。
2. 通过面包屑或者文件夹进到目标目录，能看到文件名、大小和修改时间。
3. 想让文件栏跟着终端的当前目录走，就打开跟随；只是临时去别的目录看看的话，可以先关掉。
4. 上传、下载、新建目录、重命名、删除之前，都核对一下路径。文件会传到哪台机器上，取决于当前终端连的是哪里。
5. 小的文本文件可以双击直接编辑，上限是 2 MiB。改配置文件之前先备份一份原文件，改完按程序的要求重载或重启。

不是文本的文件，或者比较大的文件，下载下来再处理。远端提示权限不够时，先确认登录的用户能不能访问这个目录，别一上来就把整个项目的权限放开。

## sudo 密码代填

在远端终端里执行 sudo 命令，弹出密码提示时，可能会出现一个「填入 sudo 密码」按钮。确认这确实是你刚执行的 sudo 命令，并且会话连的就是你想操作的那台主机，再点它。

代填失败了，或者根本没出现这个按钮，就按终端里的实际提示来处理。不要在普通的命令提示符后面直接输密码，也别把密码粘到日志或者聊天里。

## 外观与行为

在「设置 → 终端」里可以调字号、行高、配色（跟随界面／始终深色）、光标和闪烁、关键字高亮、显卡加速，还有默认本机 shell、右键行为、选中即复制、多行粘贴确认和回滚行数。终端的设置改了就直接生效，不用像其他设置页那样点统一保存。

字符显示错乱，或者刷屏的时候卡顿，可以先试着关掉显卡加速。改了默认 shell 以后，要新开一个会话才能用上。

「恢复默认（保留我的命令）」会把终端设置全部重置，但你自己保存的命令会留着。

## 断线或命令报错

远端断线了，先去「远端」页测一下 SSH，再重新开终端。命令报错的话，先找第一处明确的错误信息，分清楚是找不到命令、权限不够、网络不通，还是当前目录不对。把输出保存下来再重试，比清屏重来更容易找到问题。
