终端用于查看环境、执行命令和处理项目文件。从 Bot、应用实例或远端主机入口打开时，先确认终端标题中的主机和目录。相同的命令，在本机、远端和容器中可能操作完全不同的文件。

本机终端需要 Windows 10 1809 / Server 2019 或更新版本的 ConPTY。找不到终端入口时，先到「设置 → 功能」确认终端已开启。

## 打开并确认目标

1. 点击标题栏终端按钮，或按 `Ctrl+反引号` 展开终端面板。反引号通常在键盘数字 `1` 的左边。
2. 使用标签旁的「+」选择可用目标，也可直接从 Bot、应用实例或远端卡片打开。
3. 查看标题中的主机和当前目录。本机 PowerShell 可输入 `Get-Location`，Linux 远端可输入 `pwd`，只读确认位置。
4. 等待命令结束、提示符重新出现，再进行下一步。

![终端面板：在执行命令前核对目标和目录](/docs/screenshots/terminal-light.png)

`Ctrl+反引号` 收起的是面板，不是结束会话。要关闭会话，使用标签的关闭入口；命令仍在运行时，先确认是否应中断。

## 多会话和分屏

在标签上右键，可改名、再开一个同样的会话，或选择「左右分屏」「上下分屏」。一个标签支持两格，适合一侧查看日志、另一侧检查环境；点击终端格子后，输入才发给这一格。

双击标签也可改名。后台标签的小点用于提醒输出或命令结果：普通输出为灰点，命令成功为绿点，失败为红点；会话退出或断线时标题会变淡。回到对应标签读具体输出，不要只凭颜色判断原因。

目标支持时，可以使用右键菜单打开外部终端或保存输出。

## 复制、粘贴与搜索

- `Ctrl+C`：有选中文本时复制，没有选中文本时中断前台程序。
- `Ctrl+V` 或 `Shift+Insert`：粘贴。多行文本可能逐行执行，确认框中先逐行看完，再点「粘贴」。
- `Ctrl+Shift+F`：在输出里搜索。适合找 `error`、端口号或某个依赖名。
- `Ctrl+↑` / `Ctrl+↓`：跳到上一条／下一条命令。
- `Ctrl+点击链接`：用浏览器打开。
- `Ctrl+滚轮`、`Ctrl+=`、`Ctrl+-`：调整字号，`Ctrl+0` 还原。

右键行为可在「设置 → 终端」改为菜单，或「有选中就复制，没有就粘贴」。排错时需要右键菜单，就使用菜单模式。

## 保存常用命令

1. 打开终端中的常用命令菜单。
2. 从框架预置命令、自己保存的命令或最近命令中选择，也可搜索。
3. 选择后，命令只会填入输入行，不会立即执行。核对目标、路径和参数，再按回车。
4. 添加自己的命令时填写命令和可选名称，例如给只读检查起名「看当前目录」。

最近命令按终端目标分别记录。不要把密码、token 或一次性验证码存成常用命令。

## 使用文件栏

1. 在当前终端格子顶部点击「文件栏」。本机终端显示本机目录，远端终端显示对应主机目录。
2. 通过面包屑或文件夹进入目标目录，查看文件名、大小和修改时间。
3. 需要文件栏跟随终端目录时使用跟随入口；临时浏览其他目录时可关闭跟随。
4. 上传、下载、新建目录、重命名和删除前，核对路径。文件上传到哪台主机，以当前终端目标为准。
5. 小型文本文件可双击打开编辑；当前文本编辑上限为 2 MiB。修改配置前先备份原文件，保存后按程序要求重载或重启。

非文本或较大文件使用下载方式处理。远端权限不足时，先确认登录用户能否访问目录；不要直接对整个项目改权限。

## sudo 密码代填

远端终端识别到 sudo 密码提示时，可能出现「填入 sudo 密码」。确认这是你刚执行的 sudo 命令，并且会话属于预期主机，再使用该按钮。

代填失败或没有出现按钮时，先看终端的实际提示，按当前会话要求处理。不要在普通命令提示符下输入密码，也不要把密码粘进日志或聊天。

## 调整终端外观与操作

打开「设置 → 终端」，可调整字号、行高、跟随界面／始终深色配色、光标与闪烁、关键字高亮、显卡加速，以及默认本机 shell、右键、选中即复制、多行粘贴确认和回滚行数。终端偏好直接保存，不使用其他设置页的统一草稿。

字符渲染异常、刷屏卡顿时，可先关闭显卡加速试一次。切换默认 shell 后用新会话确认；不要期待已经运行的 shell 自动切换。

「恢复默认（保留我的命令）」会重置终端偏好，保留自己保存的命令。

## 断线或命令报错

远端断线先回「远端」页测试 SSH，再打开新终端。命令失败先读第一处明确错误，区分找不到命令、权限不足、网络失败与工作目录错误。把输出保存后再重试，比反复清屏更容易定位。
