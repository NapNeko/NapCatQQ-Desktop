这一篇带你在自己的电脑上把第一个 Bot 跑起来。我们用最省事的组合：Windows 本机 + NapCat + 直接运行，不需要服务器，也不用写一行代码。

开始之前准备两样东西：一个打算给 Bot 用的 QQ 号，以及登录着这个号的手机 QQ，等会儿扫码要用。

先提一句，配置里要填的是数字 QQ 号，不是昵称，不是手机号，也不是密码。看着像废话，但第一次在这里填错的人真不少。

## 1. 准备本机组件

Bot 要上线，先得有 QQ 和协议端这两样。

1. 打开侧栏「组件」，确认主机选的是「本机」。
2. 看 QQ 的状态，没装就点「安装」。
3. 找到 NapCat，点「安装」，需要的运行时会顺带一起准备好。
4. 等状态重新检测完，确认都已可用。

![组件页：先选择本机，再准备 QQ 和 NapCat](/docs/screenshots/components-light.png)

下载和安装的进度可以在「任务」里看。进度条半天不动的时候，别反复点「安装」，它不会因此变快，只会多排几个任务。真的失败了，就展开失败的那一步，把错误记下来再重试。下载慢可以看 [网络设置](/docs/network/)，各种状态是什么意思见 [组件管理](/docs/components/)。

如果 Desktop 检测到你电脑上装了系统 QQ，可以直接拿来用，也可以在 QQ 组件卡上点「转为 NCD 管理」，另装一份专门给 Bot 用，这样 Bot 和你平时聊天的 QQ 就不会共用同一个程序。不过要知道，程序分开了，QQ 的登录数据不一定完全隔离。

## 2. 新建 Bot

组件准备好以后，在 Desktop 里给这个账号建一份配置。

1. 打开「机器人」，点右下角带加号的「新增 Bot」。
2. 在「身份」页按下表填写。

| 项目 | 填什么 | 说明 |
| --- | --- | --- |
| QQ 账号 | 要登录的数字 QQ 号 | 创建后不能改号 |
| 实例名称 | 例如 `我的第一个 Bot` | 只用来区分卡片，和 QQ 昵称无关 |
| 底座类型 | NapCat | 后台运行的协议端 |
| 运行宿主 | 本机 | 当前这台 Windows |
| 启动方式 | 直接运行 | 本机不支持 Docker |

![新增 Bot：填写 QQ 账号和实例名称，选择 NapCat 与本机](/docs/screenshots/bot-create-light.png)

「掉线自动重启」和「定时自动重启」第一次先别开。万一启动出了问题，你会希望它停在那里让你看日志，而不是一遍遍自己重启，把日志刷得找不着头。音乐签名接口留空，「高级」里的东西保持默认就好。

3. 点右上角「保存」，确认「未保存」提示消失，回到机器人列表。

列表里多出这张卡片，QQ 号和运行位置都对，这一步就完成了。卡片显示未运行是正常的，我们还没点启动。

## 3. 启动并扫码登录

1. 在 Bot 卡片上点启动。如果提示组件缺失，回「组件」补上。
2. 打开卡片上的 WebUI，按 NapCat 页面的提示拿到二维码。
3. 用登录着这个号的手机 QQ 扫码，然后在手机上确认。
4. 回到 Desktop，看卡片上的进程状态和登录状态。

二维码过期了就刷新一下再扫。手机上弹出设备验证的话，按 QQ 的提示做完就行，这一步只能你自己来。

二维码和 WebUI 地址里带的密钥，别发到群里或者其他公开的地方。别人扫了，登上去的就是你的号。

如果你选的是 SnowLuma，它启动后会保留 QQ 的图形界面，登录方式和 NapCat 不太一样，见 [远端登录](/docs/remote-login/) 和 [机器人管理](/docs/bots/)。

## 4. 确认真的登上了

看卡片上的两个状态：

- 进程状态：协议端在运行，没有刚启动就退出。
- 登录状态：显示 QQ 已登录，而不是还在等扫码，或者显示离线。

![机器人列表：分别检查运行状态与 QQ 登录状态](/docs/screenshots/bots-light.png)

这两个状态是分开的。进程在跑，QQ 不一定登上了；QQ 登上了，也不代表应用端已经连上。之后排查问题时，经常要靠这一点判断卡在哪一步。

拿不准的话，打开卡片上的「日志」看看。别只盯着最后一行，真正的原因经常在进程退出前的那几行里。

![Bot 日志：确认启动过程，定位登录前后的错误](/docs/screenshots/bot-logs-light.png)

## 5. 停止，再启动一次

登录成功后点停止，等状态变成已停止，再启动一次。这样做是为了确认配置真的保存下来了。

重启以后要不要重新扫码，取决于 QQ 那边，Desktop 没法保证每次都免扫码。

到这里，Bot 已经能登录 QQ 了，但它还只会在线，收到消息不会有任何反应。让它保持在线，接着看 [连接应用端与 OneBot](/docs/connections/)。

## 卡住了？

| 现象 | 处理 |
| --- | --- |
| 保存时报账号或实例名称错误 | QQ 号填正整数，名称不能为空；远程模式还要选具体主机 |
| 提示组件缺失 | 回「组件 → 本机」检查 QQ、协议端和运行时 |
| 下载或安装失败 | 到「任务」找失败的那一步，先别删目录 |
| 启动后马上停止 | 看 Bot 日志，记下退出前的错误、协议端版本和 QQ 版本 |
| WebUI 打不开或要求鉴权 | 用卡片上的入口进，查启动日志，不要自己换端口 |
| 一直等待登录 | 二维码是否过期、手机是否确认、QQ 是否要求额外验证 |
| 在线但不回复 | 这很正常，还没接应用端。继续配置应用端和 OneBot 连接 |

更多情况见 [故障排查](/docs/troubleshooting/)。
