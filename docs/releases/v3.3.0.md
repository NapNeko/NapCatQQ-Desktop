三个大板块集中落地：桌面端内嵌了完整的终端面板；OneBot 调试台可以直接调接口、发消息、导出代码，还能暴露为 MCP 服务给本机 agent；应用端再添 MaiBot、Koishi、TRSS-Yunzai 三个框架。另外还有设置页「功能」开关、20 个社区主题和一批稳定性修复。

### 更新内容

#### 新增

- **终端** — 桌面端底部嵌入完整终端面板：多标签、左右分屏、搜索、命令成败标记与跳转、关键字高亮、最近/常用命令、多行粘贴确认、输出导出为文件
- **终端** — 每个标签带文件栏：面包屑导航、双击直接改小文本、拖文件进终端上传远端、「此电脑」换盘；服务器状态条实时显示 CPU / 内存 / 负载
- **终端** — sudo 代填：密码不经前端，由面板内完成；多行粘贴默认确认
- **终端** — 一键直达上下文：Bot 卡片进 Docker 容器或宿主机部署目录、远端主机卡片进 SSH、应用端实例进项目目录并自动接好 node / uv / .venv / karin 环境；标题栏开关或 `Ctrl + \`` 随手呼出
- **终端** — 设置页新增「终端」Tab：字号、行高、配色、光标、高亮、显卡加速、默认 shell、右键行为、选中即复制、回滚行数，改了立刻生效
- **OneBot 调试台** — 三栏工作台：接口目录、参数表单、事件流一屏同开；NapCat / SnowLuma 统一目录，HTTP / 正向 WS / 反向 WS 三种通道
- **OneBot 调试台** — 接口目录行以中文简介为主名，参数括注和上游简介的附属说明挪进悬停提示和文档页
- **OneBot 调试台** — 消息事件详情气泡新增快捷操作：回复 / 撤回 / 查发送者，在中栏开一个预填好参数的请求标签
- **OneBot 调试台** — 加好友 / 加群请求卡片给「同意 / 拒绝」，拒绝前二次确认
- **OneBot 调试台** — 完整消息构建器接入聊天输入框：段拼装、双向转换、实时预览
- **OneBot 调试台** — 流式接口可调用：分块上传 / 进度收拢、本机文件直接预置；`upload_file_stream` 不传参数时走普通单帧
- **OneBot 调试台** — 请求标签新增「导出调用代码」：按当前动作、参数和生效通道生成 curl / JavaScript / Python 片段，token 自动打码
- **OneBot 调试台** — 调用历史支持「对比响应」：勾选同一个接口的两条记录并排看回包，按行 diff 高亮
- **OneBot 调试台** — 「弹出为独立窗口」，与主界面调试台单窗共存
- **OneBot 调试台** — 可开成本机 agent 的 MCP 服务（`ncd-mcp`）：调试台的接口、事件流通过 MCP 暴露给本机代理；MCP 来源的调用也进历史
- **应用端 · MaiBot** — 接入 MaiBot 框架：源码安装、正向对接（协议 Bot 开端口、麦麦来连）、启动前上游条款核对；新建、导入、启停、对接全套
- **应用端 · MaiBot** — 深度配置页：模型、人格、记忆、表达学习、回复、会话规则、MCP、高级全覆盖；两份主配置强类型、停止时差量写盘保注释、运行中直接走麦麦自己的 WebUI 接口改
- **应用端 · MaiBot** — 运行期页：状态、用量、提供商与 MCP 探测、试聊 / 重启；模型页测连接拉模型、从预设挑提供商
- **应用端 · MaiBot** — WebUI 数据页搬进桌面端：提示词、学到的表达方式、黑话、人物、表情包、知识库（导入 / 图谱）、行为分数，不再跳浏览器；支持桌面端直联「试聊」
- **应用端 · MaiBot** — 插件商店（官方 plugin-repo 市场）；桌面端管的插件标记只读；在桌面端配好模型即标记 WebUI 首次配置完成
- **应用端 · MaiBot** — 远端安装：装前查 glibc / 架构 / 磁盘，缺 Python 3.12 先装好；远端下不动的由桌面端代下传上去；远端装插件也由桌面端下 tar.gz 传上；跨机对接走桌面端隧道
- **应用端 · Koishi** — 接入 Koishi 框架：官方整包安装 + 反向 WS 对接 + `koishi.yml` 插件树 + 控制台 WebSocket + 插件市场；概览（状态卡 / 运行信息 / 当前设置 / 控制台入口）、服务器、全局设置、插件（按 Schemastery schema 画表单）、添加已装、连接页
- **应用端 · Koishi** — 控制台功能原生化不再跳 WebUI：试聊（私聊 / 群聊）、指令（别名 / 权限 / 冷却 / 次数）、数据库（表目录 + 翻页只读）、文件（树 / 预览 / 编辑 / 新建改名删除）四页，页头「试聊」与概览工具直达指原生页
- **应用端 · Koishi** — 插件原文 JSON 换 CodeMirror 编辑器（着色 / 补全 / 诊断，空配置按 schema 默认值预填）；日志按 Koishi 时间 / 等级 / 来源名拆行上色
- **应用端 · TRSS-Yunzai（云崽）** — 接入云崽框架：概览、基础 / 主人与权限 / 群聊 / 渲染、插件、连接页；新增 git / redis 运行时依赖组件
- **应用端** — 应用端连接支持正向 WS：协议 Bot 开服务端、应用端连过来，跨机也走通（远端 Bot 连本机麦麦走 `-L`，本机 Bot 连远端麦麦走 `-R`，两台远端常驻 `ssh -L`）
- **应用端** — 实例详情换成左侧分组导航，保存条挪到底部；填错的页在侧栏亮红点、保存条能直接跳过去
- **应用端日志** — 每次启动另起一份（上轮留 `.1`）、按上游颜色码原样上色、长行换行；实例详情「更多」里新增「随桌面端启动」开关
- **应用端商店** — 可按分类筛选、推荐标签可改名、装不了的条目给「手动装」；商店目录支持分几份文件拉取、单文件插件同名多源依次回落
- **设置 · 功能页** — 可选模块可整块关掉：两个协议端分开开关（至少留一个）、应用端总开关 + Karin / NoneBot2 / AstrBot / MaiBot 各自开关、容器页、ncd-watch、内嵌终端；关掉的从侧栏和各页入口消失，后台也真少干活（不探测、不探远端 Docker、不写 watch 心跳）
- **外观** — 新增 20 个社区主题（Rosé Pine、Tokyo Night、Dracula、Nord、One、GitHub、Gruvbox、Solarized、Everforest、Kanagawa、Monokai 等）；主题选择器按族分组、跟随系统的暗色样式只在没选主题时生效
- **外观** — 配置原文编辑器给 YAML 着色
- **应用内更新日志** — 跳过发布正文里的下载块和页脚，只显示本版重点和改动
- **远端 Bot** — 连接页新增「从远端读取」：读回远端当前 onebot 网络配置、弹框列出增删改，确认后只填进表单不直写（#137）

#### 修复

- **配置** — 并发写共享配置文件偶发 `configuration I/O failed`（os error 2 / 32）：批量启动多个 NapCat Bot 时约三成会翻；整笔事务和单文件原子写共用一把锁，并发写测试钉住
- **配置** — 写文件先把原文件挪成 `.bak`，挪走到换上之间来读的报 NotFound：备份改成拷贝、临时文件直接原子替换
- **启动** — 自更新把 0.1.0 当当前版本：`build.rs` 原来在编译机读配置，`target` 被别的 checkout 编过就读不到产品版本号
- **托盘** — 面板点「显示主窗口」后面板自己浮着：面板 capability 不给 hide，前端那句 `hide()` 一直被拒，改由后端收起；托盘面板换自己的 capability，顺带少了用不上的窗口 / 选文件权限
- **托盘** — 托盘退出和主菜单退出各走各的：托盘退出不停本机应用端实例、不收终端
- **调试台** — 弹出窗命令原来同步执行，从 IPC 建 WebView 窗体会把主事件循环卡死（点了没反应、主窗拖不动）；改 async 后弹出窗与主窗不互卡
- **组件** — 点「安装 QQ 依赖」装错时任务挂着转圈的「安装 QQ 系统依赖」却看不到原因：失败路径补发 StepEnd / Finished，原因写进步骤日志
- **组件** — 取消组件任务的判断：队列里的任务只走队列取消，正在跑的不可取消任务（装系统包那类）被拒时不再已被掐停；Desktop 自更新的取消不再先成功再冒 task not found
- **组件** — 装卸组件后下一次探测不重探：除丢内存副本还记无效标记，装卸后的 home、布局、选中路径、needs_sudo 不再停在装之前；重探失败落档案兜底；每台机器加探测锁，冷缓存时并发只探一次
- **组件** — uv 默认版本钉住各发行版 sha256 再下载；新文件先攒 `.new` 装齐再换，装到一半失败不丢旧 uv
- **SSH** — 从本机 OpenSSH known_hosts 抄指纹：跳过 `@revoked` 吊销过的公钥；按连接用的 host + 端口找，不再拿档案显示名对；非 22 只认 `[host]:port`、主机名不分大小写、同行 `!host` 排除
- **远端适配** — 远端解压缺 unzip / tar 自动补装：个别 apt 源连不上导致整次装跳过，改成刷新失败也接着装、成败只看安装那句；Alpine 不再先跑 `apk update`
- **远端适配** — 远端 HOME 带空格或引号时 ncd-watch 停不掉：`pkill -f` 的匹配路径原先是转义外面再套一层单引号，带空格时拿到两个参数
- **远端适配** — Host::which 在 PATH 找不到时接着看 `/usr/local/bin`、`/usr/bin` 等常见目录，远端按连接记住找到的路径；SnowLuma 解析远端 bash 不再每条短脚本多两趟 exec
- **端口** — 本机挑应用端口只试 bind 回环：别的程序在 0.0.0.0 上听着也判空闲，第二个 AstrBot 实例会分到同一个 dashboard 口；现在除了 bind 再连一下 127.0.0.1
- **端口** — 远端建实例、改端口、分正向听口避开服务器上正在听的口：一次读 `/proc/net/tcp` 比对全部候选，不再逐口起 python
- **进程** — 本机跑命令超时后命令和它的子进程还在跑：超时按进程树强杀；内嵌终端测试不再被同时建的 ConPTY 输出管道吊住
- **进程** — 停应用实例连子进程一起收（适配器起的子任务不再留下）：先请它自己退，等不到再收整棵树
- **AstrBot** — 展开插件 zip 时子项名含 `..` 直接整包装不上（如 `notes..txt`）：现在只挡挪不了的（空名、`.` / `..`、带路径分隔符）；解包、展开或读 `metadata.yaml` 失败时把半成品清掉，重试不再报「已存在」
- **AstrBot** — WebUI 账号面板在读不到落盘账号时显示空用户名：和登录代填同一个兜底
- **麦麦** — 装完卡在「安装中」：安装状态只认任务结果，不再被半成品 `.venv` 提前翻成已安装
- **麦麦** — 行为页的时间按麦麦所在主机的时区折算，远端服务器是 UTC 也不再差几个小时
- **云崽** — 渲染页选「自动」整个页面崩掉；单独设置里沿用默认的项不再被序列化成 `null` 写回 YAML
- **通知** — Docker Bot 当 OneBot 发送方时把容器内端口直接写给 ncd-watch：按部署规则换宿主机口，规则里没有的带上容器名和容器内端口，由 ncd-watch 发送前 `docker inspect` 现查；一个发送方整体失败换下一个，部分成功不重发（#137）
- **远端观察** — WebUI / noVNC 隧道和 ncd-watch 的 `webuiPort` 按 `docker inspect` 读容器实际端口映射（network_mode=host 用容器内端口），读不到才按规则推；推出来的口标成推测值，不盖掉 notify.json 里已有的口（#137）
- **登录** — 暗色主题扫码登录二维码拍屏 20 次只扫出 1~3 次：改浅底深码 + 码区静区，所有主题二维码对比度 ≥ 3.5
- **UI** — 相对时间在 28、29 天和 360 多天显示「0 个月前」「0 年前」
- **UI** — 外链打不开时组件页把被拒的 Promise 吞掉没人报：统一弹「无法打开链接」错误条，连点几次只留一条
- **UI** — 对接、导入对话框晚到的失败在框已关掉后还弹出来：关框后请求挂空键、检查结果走 mutate 回调
- **UI** — 配置导入后装卸 SnowLuma 的回写拿旧副本把导入的设置盖回去：导入在写锁里提交事务、写完同步内存副本
- **UI** — 标签输入框在输入法选字时按回车提前加上；Select 下拉打开时反复重播；弹窗打开时焦点落进弹窗里；页面贴底的悬浮按钮跟着终端面板抬高

#### 改进

- **前端加载** — xterm 拆成懒加载 vendor（506 KB），启动预加载 vendor 从 1088 KB 降到 581 KB，终端面板挂上时才加载
- **前端动画** — 页面切换动画改 WAAPI 走合成线程；概览 CPU / RAM 曲线滚入交合成线程，采样不再带整页重渲
- **终端** — 收起 / 切页 / 轻量化都不断连，关标签才结束；命令菜单顶部筛选、两行条目、紧凑的添加表单
- **应用端** — 实例停止、自动启动、对接 / 解绑后的状态改走事件桥推送，不再依赖调用结果回写，状态跟在跑的实例更齐
- **远端运维** — 远端缺工具自动补装、系统包提示、compose 插件补装统一走一份实现并一起校验包名；慢镜像装系统包的上限从 180 秒提到 600 秒
- **任务** — 只有「在跑的不可取消任务」没有取消按钮，排队和等输入的照旧；取消先于队列判断，组件任务和 Desktop 自更新不再混着处理

#### 说明

- 本版数据路径与既有配置不动；覆盖安装即可
- 「功能」页开关默认全开，升级后行为与之前一致；有 Bot 在用的协议端、有实例的框架、在跑的应用端、装着 ncd-watch 的远端会在设置页被拦住，处理完再关
- MCP 服务（`ncd-mcp`）需要本机 agent 支持 MCP 客户端接入；开启后调试台能力经 stdio 暴露，访问粒度与调试台相同
- Docker 部署的协议 Bot 不给对接应用端（容器里的 127.0.0.1 不是宿主机），对接对话框会置灰并说明；要对接请换成原生部署
- 正向 WS 对接暂只对本机和远端麦麦放开；其余框架的正向配对以对接对话框的可用项为准
