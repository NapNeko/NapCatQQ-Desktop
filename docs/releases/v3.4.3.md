这一版集中打磨聊天窗口和托盘的操作体验：悬浮预览与右键菜单在同一面板内切换，聊天会话按列表位置上下翻页，首次加载也有了骨架屏过渡。

同时修复自己发送和合并转发的图片无法显示、关闭转发记录时闪回加载界面、主窗口关闭后托盘退出无响应等问题，补齐附件发送、消息复制与 Markdown 按钮交互。

### 更新内容

#### 托盘与窗口

- **悬浮预览更稳定** — 鼠标停留约半秒后再展开聊天托盘预览，减少路过图标时误触。面板展开后保持位置稳定，移动鼠标不会反复触发展开或造成偏移
- **预览与菜单连贯切换** — 在已展开的聊天预览上按右键，直接在同一个面板内切换到菜单；两种视图保持相同高度，减少跳动。菜单已打开时重复按右键也不会重新打开
- **展开与收起动效** — 调整托盘面板的淡入、淡出和内容切换，减少切换时的停顿。阴影随面板一同退场，修复面板消失后 Windows 阴影仍留在屏幕上的问题
- **托盘退出** — 修复主窗口已关闭时，从主托盘菜单点击「退出」没有反应的问题，恢复正常退出流程

#### 聊天与附件

- **会话翻页** — 选择当前会话下方的聊天时，旧消息向上退出，新消息从下方进入；选择上方的聊天时，方向相反。快速切换会接续到最后选中的会话，减少长消息列表切换时的卡顿
- **首次加载** — 聊天窗口读取账号、会话和消息时显示骨架屏，让首屏布局与后续内容衔接
- **附件输入** — 支持把图片和文件拖进聊天框，或从剪贴板粘贴附件；发送时可以查看处理与上传进度
- **发送状态** — 将发送提示收进消息旁的小型进度环，减少对消息内容的遮挡。可取消的发送任务在悬停时显示取消按钮，发送失败后仍可重试
- **文件卡片** — 长文件名自动省略，保留完整名称供悬停查看；增强默认主题下卡片边界、文字和文件类型图标的辨识度
- **账号选择** — 增加左下角账号选择按钮的左侧留白；连接状态改用带勾或横线的圆形标识，配合颜色区分，悬停时也更容易看清
- **断线恢复** — 聊天事件通道断开后自动重试，恢复连接时刷新联系人与最近会话；修复订阅过程中旧状态覆盖新连接状态的问题

#### 转发与消息内容

- **自己发送的图片** — 修复直接发送图片及自己合并转发图片后，聊天窗口或转发记录里显示「图片加载失败」的问题，补全本地图片来源与转发消息的关联
- **转发方式** — 重新整理合并转发、逐条转发的选择界面，支持一次选择最多 100 条消息。逐条转发出现部分失败时，会保留结果并提示失败情况
- **聊天记录弹窗** — 关闭时保留当前记录内容直到退场完成，修复退出过程中闪回「正在读取聊天记录」首屏的问题
- **消息复制** — 改进 Windows 剪贴板复制，按消息内容提供文字、图片和文件等格式；图片、音视频文件及合并聊天记录的复制内容更完整，GIF 等附件保留原文件
- **Markdown 与内嵌键盘** — 正确解析 Markdown 消息内容与内嵌按钮，减少编码文本和协议占位符直接露出。支持打开链接、填入命令，以及按钮指定的发送或回复操作；连接未提供的 QQ 回调能力或无法确认的操作权限，会禁用按钮并说明原因
- **输入光标** — 修复插入 @成员 后光标位置偶发错乱的问题，继续输入时保持在正确位置
