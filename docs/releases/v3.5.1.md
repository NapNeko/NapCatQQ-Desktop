本次更新改进聊天媒体与文件下载体验，并修复窗口恢复和远端 SnowLuma 启动中的问题。

### 更新内容

#### 修复

- **聊天文件** — 修复好友和群聊文件消息的下载入口，兼容不同协议版本的文件标识和消息直链。
- **聊天语音** — 首次点击即可加载并播放，补齐播放 / 暂停、进度拖动、时长、音量和倍速控件，加载失败后可重试。
- **窗口恢复** — 修复从任务栏恢复窗口时的闪跳，以及主窗口与聊天窗口长期隐藏后可能出现的交接失败，保留交接中的未发送草稿。
- **远端 SnowLuma** — 修复 Linux SSH 原生部署在断线、重连或启动失败后可能沿用失效状态的问题，避免旧连接的任务干扰新连接。

#### 改进

- **媒体选择** — 消息多选、键盘焦点和搜索定位的边框更贴合图片、视频、语音与文件卡片，减少媒体周围的空白。
- **并行下载** — 聊天文件、组件安装包和应用更新在下载源支持时自动使用多连接下载；较快连接会继续处理剩余片段，减少大文件下载末尾的等待。不支持分片的来源自动使用单连接。
- **下载恢复与文件保护** — 分片下载遇到临时断流时只补下尚未写入的部分；下载完成并通过所需校验后才替换目标文件，失败或取消不会覆盖已有完整文件。
- **SnowLuma 批量启动** — Linux SSH 原生部署复用同一主机的共享服务与已验证的初始化结果，减少重复探测和凭据校验；不同主机独立初始化，配置、进程或连接变化后重新检查。
