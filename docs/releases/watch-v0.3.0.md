本版将值守引擎接入 Windows 原生远程代理，与 Desktop 3.5.0 配套。

### 更新内容

- **Windows 原生宿主适配** — 由远程代理提供进程归属、登录状态、WebUI 读取和二维码操作，值守引擎复用现有通知与重登状态机。
- **目标身份约束** — Windows 原生进程探测需要已认证的代理宿主，缺少宿主时返回未知状态，避免按无归属的 PID 或进程名接管任务。
- **Windows 指标采集** — 增加 Windows 内存、磁盘与进程资源采集路径；Linux 与 Docker 继续使用对应的平台探测。
- **登录代数与二维码清理** — 原生宿主观测保留重置代数，关闭二维码会话时通知宿主清理辅助资源。

### 安装与验证范围

本 Release 继续提供 Linux x86_64 / aarch64 的 musl 二进制。Windows 使用 Desktop 3.5.0 随附的远程代理，不需要下载 Linux 二进制，也不单独安装 watch.exe。

相关代码与本机隔离回归已通过；Windows Server 2022 已测通基础 SSH 与代理探针，Windows 值守、用户会话恢复和 QQ 扫码尚未完成实机验收。
