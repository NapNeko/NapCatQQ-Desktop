这版减少远端监控对 NapCat WebUI 的重复登录，配合 Desktop 3.4.2 处理 WebUI 鉴权失败和登录限流问题（[#154](https://github.com/NapNeko/NapCatQQ-Desktop/issues/154)）。

### 更新内容

#### 修复

- **凭据复用** — 登录成功后，在后续探测中复用凭据，不再每轮都重新登录。token 或 WebUI 端口变化时会重新获取，凭据失效后也会重新登录
- **登录退避** — 遇到 token 错误、登录限流或两步验证要求时暂停连续登录，稍后再重试，避免后台监控不断消耗登录次数
- **错误识别** — 正确解析 WebUI 通过 HTTP 200 返回的业务错误，并保留 token 原始字符参与鉴权，避免把有效 token 处理成另一串值

### 升级说明

建议先升级 **Desktop 3.4.2**，再从组件管理更新远端 ncd-watch；Desktop 这版也修复了运行中二进制的替换和非 root 用户的启动流程。

本版没有新增配置字段，可继续使用现有监控配置。
