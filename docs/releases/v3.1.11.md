**NapCatQQ Desktop 3.1.11**

Windows 桌面控制台更新（NapCat / SnowLuma 管理）。

### 更新内容

#### 新增

- 升级启动动效、溶图过渡与主界面律动展开
- 统一任务与软件日志右键多行复制与选区持久化
- 优化标题栏按键交互并引入全局 Title Tooltip 拦截器
- 接入全局自定义右键上下文菜单与多场景交互
- 持久化 SnowLuma 包类型偏好
- 重塑首页 7:5 纯净布局与性能图表科技感流式渲染
- 重构配置漂移对话框 Diff 与选用体验
- 运行设置增加 SnowLuma Node.js 环境选择
- 本机 SnowLuma 安装走 Full/Lite 与 Node 环境选择
- 映射 Node 环境探测类型与 snowlumaNodePath 设置
- 接线 Node 探测命令与 SnowLuma daemon 路径覆盖
- daemon 按覆盖路径解析 Node 入口
- SnowLuma 启动计划按优先级解析 Node
- Windows SnowLuma Lite 编排独立 Node 依赖
- Windows SnowLuma 支持 Full/Lite 发行物
- 支持本机 Windows Node.js 安装与环境探测
- 新增 Node 环境探测模型与 SnowLuma Node 路径配置
- 增强桌面同意对话框，添加滚动进度指示和文档阅读状态

#### 修复

- 精简 SnowLuma 与 Node.js 描述并区分已安装状态
- 修复侧边栏展开态收起按钮位置溢出问题
- 修复概览页组件卡片未安装状态与可更新徽标门禁
- 回填旧版 SnowLuma 包类型标记
- 统一 SnowLuma Lite 本机门禁
- 明确 Lite 外部 Node 缺失提示
- 保留 Linux 包类型并兼容旧本机安装
- 持久化 SnowLuma 包类型并分离 Node 运行时
- 本机 SnowLuma daemon 未就绪时跳过协议加载
