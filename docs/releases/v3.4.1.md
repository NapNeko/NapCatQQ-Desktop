截图可以只复制到剪贴板了，不必每次都放进聊天框。启动后还没打开聊天页，也能直接按快捷键截图；截图被其他窗口挡住时，再按一次快捷键就能召回。

聊天滚轮、分栏拖动和页面切换也更利落了。悬浮侧栏收窄成图标卡片，概览里的 CPU / RAM 图表加了负载状态，长文本和终端面板的遮挡问题一起修了一轮。

### 更新内容

#### 新增

- **截图去向** — 截图设置里新增「截图后添加到聊天框」，默认开启，保留原来的使用方式。关闭后，截图仍可复制或另存为，完成时不会把图片塞进聊天草稿，也不会拉起聊天窗口或把焦点抢回输入框；聊天附件已满时也能继续截图
- **概览负载** — CPU / RAM 图表会根据占用显示负载状态和对应颜色。鼠标移到历史曲线上时，状态跟着那个时间点变化；曲线端点换成小猫头，填充与发光更淡一些

#### 修复

- **截图快捷键** — 修复启动后必须先进入聊天页，快捷键才会注册的问题。截图进行中再次按快捷键，会召回当前截图窗口，不再尝试开启另一轮；其他页面更新截图设置时，也会保留当前聊天会话作为接收目标
- **终端遮挡** — 打开底部终端面板时，Bot 和应用端页面的悬浮按钮留在原位，由终端面板覆盖，避免按钮跟着面板往上挤、挡住页面内容
- **界面细节** — 下拉选中项和输入框占位文本过长时统一单行省略，避免挤坏布局；弹窗关闭按钮保持固定正方形，启动屏退场的冲击波放回 Logo 下方

#### 改进

- **聊天滚动** — 滚轮输入更快响应，惯性拖尾更短。滚到一半反向滚动时会立即接管，拖动滚动条也会停止原来的惯性；向上加载历史消息时仍保留阅读位置
- **拖动尺寸** — 调整聊天分栏、输入框高度、终端高度、终端分屏和文件栏宽度时，尺寸跟着指针按帧更新。终端布局在松手后保存，减少拖动过程中的反复刷新；取消拖动、隐藏面板或切换分屏时也会收尾
- **动画与侧栏** — 页面退场和按压反馈更短，快速反向切换会从当前画面接着播放，减少动画中断后残留的缩放、透明度和位移。悬浮侧栏改成更窄的图标卡片，留出更多内容空间；经典贴边样式仍可在「设置 → 外观」切换
