这版可以直接在桌面端聊天了。NapCat 和 SnowLuma 都能用，私聊、群聊、看图、发文件都有；可以留在主窗口里，也可以单独开一个聊天窗口。顺手加了截图和滚动长截图，截完就能放进输入框。

聊天之外，NeoBot 的配置、模型、提示词、记忆和插件也能在桌面里直接管了，远端实例同样能连上面板。QQ 改成单独装一份。托盘和多窗口的资源占用也收拾了一轮：藏起来的窗口会休眠，关掉聊天窗口后会释放资源，消息和图片缓存也加了上限。

### 更新内容

#### 新增

- **聊天** — 侧栏多了「聊天」入口。好友可以按 QQ 分组找，群聊放进群盒子，会话能置顶、只看未读。每个 Bot 的联系人和消息分开；从主窗口弹出聊天时，正在写的草稿也会带过去
- **消息操作** — 回复、@、撤回自己发的消息、转发和多选合并转发都能直接做。发失败了能看原因、重新发送，切会话不会丢掉没写完的内容；想保留收到的撤回消息，可以在账号设置里开「防撤回」
- **图片与表情** — 图片点开看大图，可以缩放、拖动；语音能播放和转文字，视频、Markdown 和合并转发也能查看。QQ 表情和收藏表情可以选了发，常用 QQ 表情自带缩略图，不用等在线资源加载完才认得出来
- **聊天记录** — 最近的消息会存到本机，重开后还能看。往上翻会接着读更早的历史；搜索可以查当前会话，也能查这个账号已保存的记录，按类型、发送者、日期筛选，点结果跳回那条消息
- **账号托盘** — 可以给账号开后台接收，再放一个 QQ 头像到托盘。新消息显示红点，也可换成头像闪烁；鼠标停上去看未读会话，点一下直接打开。群聊能单独设免打扰，NapCat 还会读取 QQ 本身的群消息提醒设置
- **群文件** — 群聊里可以直接找文件、上传下载、建文件夹、改名、移动和删除，也能看剩余容量。没有权限或协议端不支持的操作会置灰；消息里的文件卡片也能下载，能看进度、取消任务，关掉面板不会中断传输
- **截图与长截图** — 默认按 `Ctrl+Alt+S` 呼出，框选后可以标注、撤销重做、复制或另存为。长截图跟着手动滚动拼接，上下都能截，截过的部分会去重，旁边能预览结果，也能暂停或撤销最近一次采集。完成后图片放进聊天草稿，确认了再发送
- **截图设置** — 快捷键可以自己改，也能选全局响应或只在程序有焦点时响应。默认截图时隐藏聊天窗口；全局快捷键在聊天窗口关闭后仍可使用
- **NeoBot 配置与模型** — 本体配置可以填表，也能直接改 TOML；供应商、密钥和模型都能在详情里改，支持拉取模型列表、测连接、给不同用途分配模型。提示词也能编辑、预览和恢复默认，还能看各部分的 Token 估算
- **NeoBot 记忆** — 可以按关键词和标签找记忆，打开看全文、编辑或删除；支持单条和批量压缩，任务进度与压缩快照也能查看
- **NeoBot 插件** — 填 GitHub 仓库地址安装，已有插件能启停、重载、更新、卸载和改配置；装之前会检查来源，遇到来源冲突会先让你核对再决定是否替换
- **NeoBot 运行与用量** — 可以查看连接、服务和后台任务，操作待机、恢复和重启，创建或修改定时任务。统计页能看消息、延迟和 API 用量，计费页能试算；对话流能跟随最近请求、看完整历史和对比两次记录
- **NeoBot 部署与登录** — 「部署」页把没启动、没填 QQ、还没对接这些问题列出来，给出对应入口。面板首次设置密码也能在桌面里完成，保存后会验证是否能登录；远端实例通过对应主机的 SSH 隧道访问面板，隧道连不上时会报错，不会连到本机同端口的服务
- **侧栏** — 「设置 → 外观」可以选悬浮卡片或经典贴边，喜欢原来可折叠侧栏的选经典即可

#### 改进

- **QQ 安装** — 组件页会从官方安装包里解出一份 QQ，单独放在桌面端管理的目录里，Bot 优先用这份。装卸和更新不会动你日常使用的系统 QQ；如果 Bot 要用系统 QQ，启动前会提醒，也能直接去装一份。这里分开的是程序文件，QQ 登录数据的存储方式不变
- **内存与后台占用** — 主托盘菜单和账号未读预览换成原生绘制，省掉菜单自己的 WebView。主窗口、调试台和聊天窗口在隐藏或闲置后会减少资源占用，关掉聊天窗口后释放它的 WebView；独立聊天窗口也少加载了一批用不到的内容
- **长时间聊天** — 消息、事件和媒体缓存加了容量上限，图片等请求也限制了同时处理的数量，减少持续收消息时的内存积累。往上看旧消息时会保留阅读位置，想回最新消息可以点右下角箭头
- **调试台** — 参数、文档和回包可以分别收起来，再展开时内容还在；参数填错了，在顶部集中提示，点一下跳到对应字段。发请求统一用顶栏选的通道。JSON 编辑器补了行号、折叠、自动缩进和括号配对，Tab 可以接受补全，只读回包也能折叠着看
- **应用端** — 新建实例默认不随桌面端启动，需要的再手动打开这个开关
- **NeoBot 编辑** — 在同一个实例详情里切页，没保存的改动会留着。保存时会检查版本，如果面板里的内容已经被改过，会提示冲突并保留当前草稿，避免把另一边的改动直接盖掉

#### 修复

- **NeoBot 配置** — 之前有些对接写进了 `data/config.toml`，NeoBot 实际读的却是 `app/data/config.toml`，导致填好了也不生效。现在导入、编辑和备份都按实际目录走，启动时也固定到实例自己的目录；旧对接符合迁移条件的会自动搬过去
- **NeoBot 重启** — 在上游面板点重启后，桌面端之前会把它当成已经停止，日志和停止按钮也跟着失效。现在会继续跟踪重启后的进程；其他框架真正退出时，也不会把残留子进程误认成主进程
- **Bot 日志** — 切到别的页面期间收到的日志会留在缓冲里，回来后还能看，之前这段会丢
- **Windows 启动** — 修复正式版程序因主线程栈不足，打开就退出的问题

#### 说明

- 聊天默认开启，不用的话可以在「设置 → 功能」关掉。聊天窗口、后台接收、账号托盘和截图快捷键会一起停掉，已有记录和设置保留；重新开启会恢复原来的后台设置。每个账号的后台接收、托盘和防撤回默认都关着
- 本机只保留有条数和容量上限的近期聊天记录，消息记录不随配置备份导出。草稿会在退出程序后清掉
- NeoBot 的面板管理页要实例正在运行、控制台能连上，登录需 NeoBot `1.2.4a1` 或更新版本；具体操作取决于上游是否提供对应接口，旧版缺少时会提示升级。第三方插件自己的页面仍从原入口打开
- NeoBot 编辑草稿只在当前实例详情里保留，离开详情后会清掉。导入只有 `data/config.toml` 的打包版项目时，先按提示把数据整理到 `app/data`
