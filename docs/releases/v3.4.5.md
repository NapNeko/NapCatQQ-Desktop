### 更新内容

- **下载加速** — 按实际吞吐量选择直连或镜像，大文件分片也先测速；持续低速时自动尝试其他源，修复分片失败后无法回退的问题。组件安装和 Desktop 更新显示当前下载源与切换原因，Node 安装包使用对应二进制镜像
- **下载缓存清理** — 在「设置 → 数据」查看安装包、旧 Desktop 更新包和下载暂存文件的占用，按类别清理并查看跳过或失败的原因。安装、更新和数据迁移期间会保护正在使用的缓存；配置、聊天记录、安装日志和另存的文件保持独立
- **SnowLuma 多账号流量统计** — 同一主机上共用 SnowLuma 的多个 Bot 分别记录收发数据，后启动的账号也能加入采集；修改指标开关和采样间隔后会同步更新采集配置
- **流量节点归属** — 修复多个连接使用同一地址和端口、不同路径时的统计混淆，保留各账号的独立节点计数
- **指标界面刷新** — 修复切换 Bot 后短暂显示上一账号数据，以及慢请求覆盖较新统计的问题
