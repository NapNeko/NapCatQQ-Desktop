本次更新修复 Python 应用安装长时间没有反馈、安装依赖时界面卡顿的问题，并完善 SnowLuma 扫码恢复。

### 更新内容

#### 修复

- **安装反馈** — NeoBot、AstrBot、NoneBot2、MaiBot 的安装过程显示当前阶段和等待时间，长时间没有新输出时给出排查提示；补齐网络请求、安装锁和远端命令的等待边界。
- **安装时的界面响应** — 减少安装日志和任务进度的重复刷新，省略调试输出与逐包清单，保留阶段汇总、必要警告及错误；侧栏统计任务数量时不再重复处理日志历史。
- **取消远端安装** — SSH 通道建立和命令提交阶段也会响应超时及取消，避免任务停留在进行中。
- **SnowLuma 扫码恢复** — 分轮恢复扫码通道和获取二维码，保留尚未执行的刷新请求，减少慢 SSH 下的超时叠加；完善会话保存和 QQ 按钮识别。
- **二维码显示** — 解码或重绘失败时继续显示经过校验的有效截图，避免丢掉仍可扫码的画面。

#### 改进

- **Python 包源** — 在「设置 → 网络」中选择跟随 uv 配置、PyPI 原站、清华镜像或自定义地址，保存后用于新安装任务。上游锁定的依赖源保持原有规则。

远端 uv 使用服务器自身的网络。遇到包源连接问题时，可选择合适的 Python 包源，保存后重新提交安装任务。
