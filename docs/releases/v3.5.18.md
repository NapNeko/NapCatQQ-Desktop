本版调整应用端管理方式，并改进远端连接恢复与容器管理。

### 更新内容

#### 应用端管理调整

- 应用实例详情默认提供配置文件编辑器，保留安装、启停、日志、版本、一键对接和可用的 WebUI 入口。
- 移除桌面端内置的框架专属配置表单、插件商店和业务管理页面。需要管理插件或其他框架功能时，请使用对应框架的 WebUI 或其他官方方式。
- 编辑器保留草稿、外部修改冲突提示和保存备份；配置读取与保存失败会显示提示。远端主机已移除时，可单独移除实例记录。

#### 稳定性与体验

- 改进远端 SSH 会话和隧道的关闭与恢复，减少配置读取互相阻塞的情况，并优化远端配置文件读取速度。
- 改进 Docker 和 Podman 引擎切换、容器资源页面与错误提示，操作进行时避免切换到其他引擎。
- 调整功能设置页面及 Linux 窗口背景，修复选择框清空时的受控状态问题。

#### 说明

- 配置原文保存后的生效方式取决于各框架和配置文件，请留意编辑器中的提示；需要重载或重启时请按提示操作。
- 远端连接改动已通过相关自动化检查；Windows 桌面端真实远端断线恢复及聊天收发仍需实机验证。
