改善 Linux 桌面的托盘、窗口交互、组件安装与外部链接打开体验，新增 Podman 引擎选择。

### 修复

- **Linux 托盘重复** — 主托盘和账号托盘统一使用系统 AppIndicator，避免 KDE 同时显示两个图标；托盘名称显示为 NapCatQQ Desktop。主托盘直接提供 Bot 启停、WebUI / noVNC、恢复窗口和退出操作，不再从系统菜单打开另一层主托盘面板。
- **Linux 界面卡顿与透明窗口** — 主窗口、聊天窗口和调试窗口使用不透明画布，移除根节点圆角裁剪，规避透明 WebView 的重绘问题；Linux 窗口暂时使用直角。
- **AppImage 外部链接** — 打开项目仓库、WebUI、noVNC 和更新下载页时，隔离 AppImage 自带的库搜索路径，避免系统浏览器加载不兼容的库；浏览器启动失败时显示错误提示。
- **组件页滚动条** — 为卡片与滚动条保留间距，限制滚动条的绘制范围，避免盖过右列卡片和终端面板。
- **AppImage 组件安装** — 本机命令和终端同样隔离 AppImage 的库环境，修复系统 xz 加载旧版 liblzma 导致 Node.js 解压失败的问题。
- **noVNC 安装提权** — 缺少 sudo 权限时提示输入密码，并在确认后重试原任务；本机密码仅用于本次安装。
- **手动启动显示窗口** — “仅托盘”只对登录自启生效；退出后从应用启动器或直接运行程序，会立即打开主窗口，无需再次点击托盘。

### 新增

- **Podman** — Linux 组件页可为本机或远端主机选择 Docker / Podman，并保存选择。探测、拉镜像、Compose 部署和容器管理使用所选引擎；缺少 Podman / Compose 时可通过系统包管理器安装。Podman 使用当前用户的容器存储，已有容器 Bot 配置的主机需先迁移或移除配置后切换引擎。
