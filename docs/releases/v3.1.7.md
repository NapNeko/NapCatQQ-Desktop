NapCatQQ Desktop v3.1.7 发布，集中修复 NapCat 与 SnowLuma 登录状态卡片更新滞后、旧状态残留和误报掉线的问题。

### 更新内容

#### 修复

- WebUI、SSH 隧道或网络探测暂时失败时，登录状态会回到“探测登录”，不再直接误报 QQ 掉线，也不会因此触发离线通知或自动重启。
- NapCat 在线转离线增加连续样本确认，并正确识别“会话仍存在但暂时离线”的上游状态，减少瞬时抖动造成的误判。
- SnowLuma 对齐最新上游 Hook 状态语义：扫码前可及时显示“等待扫码”，注入异常不再当作掉线，停止状态观察也不会伪造离线事件。
- SnowLuma daemon 状态按本机和各远端服务器隔离，单台远端主机异常不再污染其它 Bot 的卡片、WebUI 按钮和告警。
- 刷新页面或重新打开窗口时以后端快照为准，及时清除已停止、已删除或探测失效 Bot 遗留的绿色登录状态。

#### 说明

- “探测登录”表示 Desktop 暂时无法确认 QQ 登录状态，并不代表已经掉线；探测恢复后卡片会自动更新为可信状态。
