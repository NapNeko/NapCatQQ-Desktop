小补丁一个：新增「VC++ 运行库」组件。NapCat 官方注入器（NapCatWinBootMain/Hook）依赖 VC++ 运行库，机器缺它时注入器会秒退、只留下一行看不懂的报错——现在组件页可以一键检测、一键补装，装/更新 NapCat 时也会自动带上。顺带把组件「卸载」入口按实际能力分了流，系统级安装的组件改为引导去 Windows 设置里卸载。

### 更新内容

#### 新增

- **组件 · VC++ 运行库** — 一键检测与安装：自动读注册表判断装没装（已装的机器无感）；未装时下载微软官方安装包（固定版本 14.44.35211.0，下载后校验 SHA256）静默安装，一次 UAC 弹窗即可完成；装到一半失败不用重新下载，再点一次接着装
- **组件 · VC++ 运行库** — 装或更新 NapCat 时自动补齐缺失的运行库；启动 NapCat Bot 时若缺运行库会被拦下并提示到组件页处理，不再给指向不明的注入器退出日志

#### 修复

- **应用图标** — macOS 应用包注册新版 ICNS，Dock 显示新版图标

#### 改进

- **组件** — 卸载入口按组件实际能力分流：组件自己管卸载的照旧；VC++ 运行库、本控制台（MSI）这类在系统里注册的组件，右键菜单与卸载按钮换成「在系统中卸载…」，点击直达 Windows「设置 → 应用 → 已安装的应用」，找对应条目手动卸载；不具备卸载语义的组件不再显示点了会弹英文报错的卸载项

#### 说明

- 安装 VC++ 运行库需要管理员权限（弹一次 UAC 确认）；若安装器返回「需要重启后生效」，重启电脑后再启动 NapCat
- 该检测只针对 Windows 本机；远端 Linux 部署链路不受影响
- 本版数据路径与既有配置不动；覆盖安装即可
