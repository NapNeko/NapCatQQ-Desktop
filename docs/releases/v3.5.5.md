本次更新加入服务器间整套 Bot 迁移与本机 MCP 接入，并收整相关界面，让常用操作更清晰。

### 更新内容

#### 新增

- **服务器间迁移** — 从 Bot 卡片菜单选择目标服务器，预检后迁移协议端与关联应用的配置和数据，自动重建依赖，保留源目录并提供回退。首版支持远端 Linux 原生 NapCat / SnowLuma 冷启动，以及已关联的 Karin、NoneBot2 项目。
- **MCP 接入** — 本机 AI 客户端可查询 Bot、应用端、服务器和任务状态，读取缓存日志、搜索 OneBot 动作并辅助诊断；默认关闭，启用后默认只读。

#### 改进

- **操作界面** — MCP 设置突出连接状态与配置复制，高级权限、端口和令牌管理按需展开；迁移进度聚合展示，回退操作按需展开。
- **MCP 权限** — 在桌面端管理写入与危险操作权限，使用独立系统凭据保存令牌，支持重置令牌，并对输出进行脱敏和限额处理。

#### 修复

- **迁移检查** — 检查仍持有项目写入句柄的后台进程，避免生成不一致快照；修正相似路径的误替换，目标进程退出时明确提示恢复处理。
- **MCP 文本输入** — 修复普通指令文本和带冒号的名称被误判为本机文件路径的问题。
- **QQ 安装** — 修复远端安装和更新的提权流程，提权失败后保留重试入口，并更准确地显示组件子任务进度。
- **头像与配置** — 修复 QQ 头像缓存长期不更新，以及 AstrBot 高级配置中特殊字段和敏感状态的处理问题。

#### 说明

- **迁移范围** — 外部数据库、外部挂载和项目外路径需单独处理；跨服务器后 QQ 可能需要重新登录。目标端产生新数据后回退需确认丢弃该部分数据，详情见迁移指南。
- **MCP 授权** — 一次性确认令牌用于请求重放校验，不代表人工审批；未知动作、凭据读取与本机文件操作不开放。
