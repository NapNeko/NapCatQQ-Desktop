**NapCatQQ Desktop 3.2.1**

应用端可以当实例来管：Karin、NoneBot2、AstrBot 能在桌面里创建、启停、看日志、对接 Bot。已经在跑的项目可以导入接管；Bot 和应用不在同一台机器也能连。3.2.0 没打出安装包，本版是相对 3.1.14 的首次 3.2 公开发布。

### 更新内容

#### 新增

- **应用端** — 侧栏多了一栏：列表、详情、启停、日志。Karin / NoneBot2 / AstrBot 各自带运行依赖（Node.js、uv 等），和协议 Bot 用 OneBot 反向 WebSocket 对接
- **Karin** — 创建时可自选安装目录，也可一并装渲染器；详情里有官方插件市场，插件配置能按表单填，也能看源码
- **NoneBot2** — 官方适配器店和插件店，另有连接页；商店里装的适配器按项目配置注册
- **AstrBot** — 可创建实例、管 WebUI 账号；详情里配模型提供商、对话默认值、人格、知识库、会话规则和子代理。实例在跑且能登录 Dashboard 时即时写入，停着只改配置
- **提供商预设** — OpenAI、DeepSeek、智谱 GLM、Gemini、Ollama 等按上游模板添加，再填密钥
- **跨机对接** — 同一台、本机 Bot 连远端应用、远端 Bot 连本机应用、两台远端互连都开了。跨机走 SSH 隧道（本机侧由桌面拨号，远端对远端在应用机上常驻）
- **导入已有项目** — 选目录即可识别 Karin / NoneBot2 / AstrBot，接管启停和日志；目录里已经对上某台 Bot 时会认领这条对接。导入的目录不会被脚手架改写，删实例默认不拆项目

#### 改进

- NoneBot2 商店切 Tab 不再整表重拉
- 已经对接过的实例，改端口或 token 会更新这条对接，不会再插一条
- AstrBot 控制面改成紧凑列表，点进去再编辑；各配置页共用顶部保存条，空态能跳到对应页
- 运行失败改成短提示，并指去看日志
- 配置原文用 CodeMirror 高亮，长文件在框里滚，不再把整页撑开
- 概览问候和吉祥物台词更口语
- 设置、机器人、应用端、组件等页收紧了一轮常驻说明

#### 修复

- 启动 Bot 时配置冲突一多，底部「应用并启动」会被裁掉，或被右下角加号挡住
- 配置页保存遇到冲突时，按钮不再写成「启动」
- 应用详情页开着时点侧栏可能没反应
- 展开 / 收起动画偶尔卡在半道

#### 说明

- 3.2.0 发版构建没过，没有上架安装包。上面这些是相对 **3.1.14** 的 3.2 能力，不是只修了构建。若要看完整提交，请对比 `v3.1.14...v3.2.1`
- 人格 / 知识库 / 会话规则要 AstrBot 在跑、Dashboard 能登录才会即时落库；没启动时先改配置、保存后再开
- 关掉桌面会停本机应用实例；远端应用实例不跟着停
- 既有 Bot 与覆盖升级路径不变
