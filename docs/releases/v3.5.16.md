修复 SnowLuma 容器首次启动后很快停止、用户协议与隐私政策无法加载，导致无法继续启动的问题。

### 更新内容

#### 修复

- **容器协议确认** — Docker / Podman 容器停止后仍可阅读用户协议与隐私政策、保存同意记录，确认后继续启动，无需抢在容器停止前操作 WebUI。
- **同意记录保留** — 容器重建时保留本次确认记录，并统一运行数据与持久化数据卷的目录，避免新版镜像重建后反复要求同意协议。
- **协议读取错误** — 协议缺失、读取失败或版本变化时给出明确提示，重新确认当前版本后再启动。

#### 说明

- 已遇到此问题的用户升级后重新点击启动即可，无需删除容器或数据卷。
- 本次修复针对 SnowLuma 容器的协议确认流程；Windows 原生 NapCat / SnowLuma 加载问题仍在 #190 跟进。
