**V3 正式版。** 从 Python / PySide6 重写为 **Rust + Tauri + React** 的 Windows 桌面控制台，用于管理 [NapCatQQ](https://github.com/NapNeko/NapCatQQ) 与 [SnowLuma](https://github.com/SnowLuma/SnowLuma)。

装完就能管 Bot：本机起停、远端部署、看日志、装组件，一个窗口搞定。

### 更新内容

#### 亮点

- **整栈重写** — 安装包更干净，杀软误报更少，冷启动与批量启停更轻
- **本机 + 远端** — 本机 Native；远端 Linux 经 SSH 部署与管理
- **双框架** — NapCat / SnowLuma 创建、启动、停止、日志与 WebUI
- **组件自助装** — Node、QQ、框架等在组件页安装与更新
- **配置与程序分离** — 数据在 `%ProgramData%\NapCatQQ Desktop`，重装不易丢设置
- **旧版可覆盖升** — 与 V2 同一 UpgradeCode，直接装新 MSI 即可

#### 说明

- 旧 Python 实现归档在 [`v1`](https://github.com/NapNeko/NapCatQQ-Desktop/tree/v1) 分支；当前主线为 `main`
- V2 → V3 跨度极大；细节见完整提交记录链接（页脚）
