继续修复 Linux 桌面的窗口卡死、滚动条遮挡与组件安装问题。

### 更新内容

#### 修复

- **Linux 窗口交互** — 在 WebView 初始化前启用兼容渲染，避开部分 Wayland / 显卡环境下的 DMA-BUF 与硬件合成问题，改善点击输入框、打开对话框或终端后卡死、画面透明的情况；保留手动设置的渲染环境变量。#170
- **组件页滚动条** — 增加右侧内容间距，并在打开终端时缩短页面滚动区域，让滚动条停在终端上方。#173
- **sudo 密码框** — 修复后台安装任务在提权错误后追加“任务失败”，导致前端漏掉密码提示的问题；noVNC、QQ 及相关协议端安装可继续输入密码并重试原操作。#175
- **AppImage 系统命令** — 清理传给系统工具的 AppImage 启动变量，并将继承的临时挂载工作目录移到宿主机目录，避免 mise 等工具误认程序名。继续隔离打包的动态库，供系统 xz 正常解压 Node.js 安装包。#174 #175

#### 改进

- **Node.js 独立安装** — 已检测到系统或版本管理器中的 Node.js 时，组件卡片仍提供“独立安装”，可在组件目录安装托管版本，保留原有 Node.js。#174

#### 说明

- Linux 渲染兼容设置、页面布局和提权流程已补充验证；Fedora 44 KDE、Gear Lever 与 SELinux Enforcing 的组合仍需实机反馈，相关 issue 保持打开。
