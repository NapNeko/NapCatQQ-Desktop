**NapCatQQ Desktop 3.1.14**

定时自动重启终于真的会重启，还能定到具体时刻；首屏和吉祥物大换新；Bot 启动前先把依赖查清楚，并修掉几处误报与闪窗。

### 更新内容

#### 新增

- **定时自动重启真正生效** — 之前这个开关只是存进配置、显示在卡片上，并没有东西去执行。现在 Bot 运行中会按计划自动重启，周期从每次进入运行状态或上次重启起算；改了计划不会立刻触发一次
- **定到具体时刻** — 除了「每隔 N 分钟 / 小时 / 天」，新增「每天 / 每周 / 每月 + 时刻」，也可以直接写 cron 表达式（本地时区）。编辑时会即时校验并显示接下来几次触发时间；表达式写错保存时直接拦住
- **随时段变化的首屏** — 概览 Hello 卡变成一片天幕：早晨、正午、傍晚、深夜各有配色，白天飘云、夜里有星星和流星，问候语逐字出现，页面角落柔光也跟着时段变色
- **会动的吉祥物** — 三双眼睛各自眨、眼珠跟着鼠标看；戳一下会蹦、歪头、点头或把猫举起来，配一句话和一个表情；实例出问题或上线时她会主动提醒；久不操作会打瞌睡，一有动静就醒
- **Bot 启动预检** — 启动前按依赖关系检查框架和运行依赖（QQ、Node.js 等），缺什么直接说明是缺失、不可用还是未能确认，不再进入「启动中 → 崩溃」；探测本身失败不会拦启动
- **安装排队提示** — 组件安装排队时会说明在等什么（等待前置组件、等待包管理器空闲）

#### 改进

- 主题切换过场重做：从点击处先蓄力，再以光波揭开新主题
- 启动闪屏重做：主窗口等首帧真正画好再显示，不再先闪一下边框阴影
- 概览通知切页回来仍在，不会被日志刷掉
- Bot 卡片上的重启计划改成一句话（如「每天 04:00 · 离线时」）
- 组件列表对「已安装但不可用」的 Node.js 给出明确徽章（版本不符 / 无法运行），不再当成未安装
- 所有新动效都遵循动效档位设置与系统「减少动态效果」偏好

#### 修复

- 指标页 OneBot 出入站消息计数恒为 0：探针改挂 Node 核心网络模块，NapCat 与 SnowLuma 的正向、反向连接都能统计
- 用户协议 / 隐私政策同意不再因安装版与本地构建之间的换行差异反复弹出，只有协议版本升级才需要重新同意
- Windows 下 Node.js 探测路径错误导致误判未安装
- 运行设置页探测 Node.js 时闪现命令行窗口
- SnowLuma 未手改的配置被误报为「配置漂移」；冲突对话框差异项较多时无法滚动

#### 说明

- **升级前请看一眼各 Bot 的「定时自动重启」开关**：以前打开了也不会生效，这版开始会真的按计划重启。不需要的请关掉
- 旧配置不用改：没有新字段的 `autoRestartSchedule` 仍按「每隔 N 单位」读取
- 组件安装与依赖解析的编排在后端重构（统一依赖图与执行器），不影响既有配置与覆盖升级
