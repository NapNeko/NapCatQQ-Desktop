NapCatQQ Desktop v3.1.10 发布，重点改进远端 Linux 主机的 Bot 发现与导入：自动探测远端已安装的 NapCat / SnowLuma、一键导入运行态 Bot 并迁移网络配置，同时支持从本机 SSH 配置勾选导入远端主机；并修掉一批远端 SnowLuma 连接稳定性问题。

### 更新内容

#### 新增

- 远端主机页支持从本机 SSH 配置（known_hosts / config）勾选导入：自动发现已连接过的远端主机并写入指纹，省去手动填地址。
- 自动探测远端 Linux 已安装的 NapCat / SnowLuma 并展示安装库存：在远端页能看到主机上装了哪些 Bot、装在哪，不用再凭记忆填路径。
- 支持从远端库存一键导入运行态 Bot：连同 onebot 网络配置一起迁移，导入后在连接页直接可用，不用重新配地址与端口。
- SnowLuma 全局 WebUI 支持密码接管：配置页可填 WebUI 接管密码，远端启动时自动用该密码登录并接管，不用每次手动登录。
- 主题切换改用 View Transitions 圆形扩散揭示动画。

#### 改进

- Bot 列表卡上的「运行位置」改显示主机名与档案名，不再露出内部 id。
- SnowLuma 卡片探测失败时给出更明确的中文文案，并移除了无意义的 UIN 副标题。

#### 修复

- 修了远端 SnowLuma / NapCat 配置热推送在 SSH 断开后死隧道刷屏的问题；现在重连后会拆掉旧 WebUI 隧道再建新的。
- 停止远端 SnowLuma Bot 时先停 poller 再换 SSH Host，避免残留进程占端口。
- 冷启动复用远端 QQ pidfile 前会核对账号是否对得上，防止串号复用。
- SnowLuma WebUI 登录改为单飞：密码错误或触发 429 后停止重试，不再无脑刷屏。
- 启动失败只弹一条提示，不再重复弹窗；门禁改为读库存包形态，缺包时提示更清楚。
- 外来安装的 SnowLuma secret 路径不在 workspace 下时回退探测，不再误判为缺失。
