NapCatQQ Desktop v3.1.9 发布，重做 Windows 本机 QQ 的安装与卸载链路：安装包本地缓存复用、支持普通权限下通过 UAC 提权安装，新增直接卸载 QQ 的能力；同时修复停止 SnowLuma Bot 后 WebUI 进程残留的问题。

### 更新内容

#### 改进

- QQ 安装包不再每次重新下载：安装包保存到数据目录的缓存文件夹（固定文件名），重复安装或上次失败后重试时直接复用已有安装包；只有安装成功才会清理。
- 普通权限运行 Desktop 时安装 QQ 会弹出 UAC 提权确认；若提权被取消或失败，会明确提示「以管理员身份运行后重试」，且已下载的安装包保留，重试无需重新下载。
- 安装包下载改用切片下载，大文件场景速度更稳。

#### 新增

- Windows 上可以直接在本程序内卸载 QQ：自动定位官方卸载器并静默完成卸载，不再要求手动去系统「应用和功能」操作；未安装 QQ 时执行卸载会直接视为已完成。

#### 修复

- 停止本机 SnowLuma Bot 后，WebUI 对应的 node 进程现在会真正退出，不再残留占用端口；此前再次启动会因端口被占而探活失败（需先手动结束 node）。
- Windows 主机上探测 Docker 不再触发多余的 UAC 提权弹窗（此前误走了 Linux 的 sudo 兜底逻辑）。
