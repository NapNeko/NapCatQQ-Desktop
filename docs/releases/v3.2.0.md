**NapCatQQ Desktop 3.2.0**

AstrBot 可以在桌面里当应用实例来管：对接 Bot、改模型和对话、人格与知识库。另外修了启动时配置冲突对话框的按钮被挡住、侧栏点了没反应。

### 更新内容

#### 新增

- **AstrBot 应用实例** — 应用端可创建、启停 AstrBot，对接 OneBot，并管理 WebUI 账号
- **AstrBot 控制面** — 详情里直接配模型提供商、对话默认值、人格、知识库、会话规则和子代理；实例在跑且能登录 Dashboard 时即时写入，停着只改配置
- **提供商预设** — OpenAI、DeepSeek、智谱 GLM、Gemini、Ollama 等按上游模板添加，再填密钥

#### 改进

- 控制面改成紧凑列表，点进去再编辑；各配置页共用顶部保存条，空态可跳到对应页
- 插件配置支持按 schema 填表，也仍可切到源码
- 概览问候和吉祥物台词更口语
- 设置、机器人、应用端、组件等页收紧了一轮常驻说明

#### 修复

- 启动 Bot 时配置冲突一多，底部「应用并启动」会被裁掉，或被右下角加号挡住
- 配置页保存遇到冲突时，按钮不再写成「启动」
- 应用详情页开着时点侧栏可能没反应：导航不再被页面里的持续更新卡住

#### 说明

- 人格 / 知识库 / 会话规则要实例在跑、Dashboard 能登录才会即时落库；没启动时先改配置、保存后再开
- 既有 Bot 与覆盖升级路径不变
