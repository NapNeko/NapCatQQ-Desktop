本次更新增加 Linux 桌面支持，修复远端 SnowLuma 首次安装后的识别问题，并增加本机目录快捷入口。

### 更新内容

#### 修复

- **Linux 主题切换** — 修复保存新主题时程序崩溃的问题，Linux 桌面直接切换主题。
- **窗口外框与拖动** — 补齐 Linux / Windows 10 窗口圆角，增加八方向尺寸拖动热区；最大化和全屏时使用直角。Windows 10 的圆角兼容模式不保留系统阴影。
- **远端 SnowLuma 安装** — 修复新安装尚未生成运行配置时，组件被误判为未安装的问题。
- **Linux 本机安装** — 修正下载日志误标远端、QQ 依赖混入远端部署工具及 NC / SL / QQ 无法输入本机 sudo 密码重试的问题；重试保留 SnowLuma 包型。本机 SnowLuma 门禁与实际启动目录保持一致。
- **应用端安装与识别** — 修复 MaiBot 源码未附锁文件时安装失败、新版监听端口与配置不一致、NoneBot2 / MaiBot 半安装被判为就绪，以及云崽子进程未沿用所选工具链的问题。

#### 新增

- **Linux 桌面** — 提供 deb / AppImage 安装包，支持本机 NapCat / SnowLuma、应用端、内嵌终端及远端管理；Linux 使用系统托盘和手动更新，原生截图暂不支持。
- **本机 Linux Docker** — 可在本机拉取镜像并创建 NapCat / SnowLuma Bot，与远程部署共用架构、镜像和启动校验，部署数据保存在 Desktop 数据目录的 `docker/` 下。
- **界面缩放** — 设置 → 外观支持 100% / 125% / 150%，保存后同步到主界面、聊天和调试窗口，重启后保留。
- **Linux 原生托盘面板** — 支持 XEmbed 的环境可右键直接打开与 Windows 共用布局的自绘面板，其余环境保留系统菜单入口。支持 Bot 操作、账号菜单及未读预览，跟随主题、圆角与界面缩放，不创建 WebView；主窗口可继续使用 Wayland。

#### 改进

- **Linux 启动窗口** — 根据显示器可用区域与系统 DPI 自适应初始大小，大屏幕使用更大的窗口，小屏幕同步收缩最小尺寸，轻量模式恢复时同样生效。
- **Linux Dock 图标** — 对齐 Wayland 应用标识与桌面入口，修复 Dock 中缺少 NCD 图标的问题；开发运行自动准备独立的用户级图标入口。
- **本机目录入口** — 可从组件右键菜单和应用端实例卡片直接打开本机安装目录；未安装的实例隐藏该入口。（[#164](https://github.com/NapNeko/NapCatQQ-Desktop/pull/164)，感谢 @setobox）
- **应用端操作** — 为悬浮操作按钮补充无障碍名称。（[#166](https://github.com/NapNeko/NapCatQQ-Desktop/pull/166)，感谢 @setobox）

诊断 Agent 继续在独立分支打磨，本版不包含该功能。
