NapCatQQ Desktop v3.1.6 发布，改进应用内更新体验：安装可见进度，装完自动重新打开。

### 更新内容

#### 修复

- 修复应用内更新 Desktop 时几乎无安装界面、装完也不会自动重启的问题（[#126](https://github.com/NapNeko/NapCatQQ-Desktop/issues/126)）。
- 安装阶段改为显示系统进度条（`/passive`），不再完全静默。
- 安装完成后会自动重新打开 Desktop（等待旧进程退出且新版本落盘后再启动）。
- 启动时若检测到上次更新成功 / 未完成 / 失败，会给出一次性提示。

#### 说明

- 更新前仍需先停止本机正在运行的 Bot。
- 若 UAC 被取消或安装失败，可到「设置 · 关于」重新检查更新；也可查看安装日志。
