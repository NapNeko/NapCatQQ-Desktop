本版重点改善远端 Bot 的状态恢复和扫码重登。断网重连后能重新接管登录状态，手机退出账号导致 QQ 更换进程时，也能恢复扫码通道。

同时新增 SnowLuma 简化扫码、远端同机重登互助和 Docker 资源管理，并调整 Bot 列表、配置页与组件管理的操作布局。

### 更新内容

#### 扫码与远端恢复

- **SnowLuma 简化扫码** — 本机 Windows、远端 Linux 和 Docker 的冷启动实例可在 Desktop 中获取登录二维码。截图中的二维码会先在本地识别，再按 Desktop 样式重新生成；控件不可用时可打开 QQ 或 VNC 继续操作
- **二维码过期自动刷新** — 过期后自动请求新码，获取暂时失败时延长重试间隔。已扫码、等待手机确认时保持当前登录流程；关闭窗口或更换 QQ 进程后，旧二维码和迟到的解析结果不会重新显示
- **退出账号后重新扫码** — QQ 退出账号并更换主进程后，校验所属账号、恢复注入并重新绑定扫码会话。扫码登录了其他账号时，自动重启对应的冷启动 Bot，回到重新登录流程
- **重连与手动刷新** — 修复断网重连后长时间等待 WebUI、Bot 状态恢复缓慢和刷新按钮未完成实际探测的问题。聊天账号随登录状态变化更新，避免 QQ 已掉线却仍显示已连接；远端指标读取失败也会区分断网与探针未启用
- **VNC 通道恢复** — 打开远端 QQ 界面前检查并恢复 VNC 服务与访问通道，修复重连后地址仍指向失效连接、无法连接服务器的问题

#### 管理与通知

- **Docker 资源管理** — 扩展容器、镜像、网络和数据卷管理页面，提供容器创建、资源查看与相应管理操作。操作范围以当前选择的远端主机为准
- **同机重登互助** — 配置互助 Bot 和管理员后，可由同一远端主机上的在线 Bot 发送掉线通知与重登二维码，支持管理员请求刷新。二维码只发送到管理员私聊，群目标收到文字提醒；需要配套更新 ncd-watch
- **管理界面调整** — Bot 卡片突出启停与扫码操作，将辅助操作收进菜单，调整资源指标和待机信息。配置页重新整理账号、宿主与连接编辑区域，统一头像回退、组件卡片和主机切换器的展示

### 升级说明

使用远端重登互助时，升级 Desktop 后，请在「组件」页将远端 **ncd-watch 更新至 0.2.8**，再同步通知配置。互助 Bot 需要通用正向 WebSocket，管理员账号需单独配置。Desktop 升级不会自动替换远端 ncd-watch 二进制。

简化扫码依赖 QQ 的图形会话与可用控件。热启动、控件不可用或窗口受遮挡时，请使用 QQ / VNC 登录。
