**3.1.0** 聚焦运行时可观测性与 Docker 部署体验：看清本机/远端资源与 Bot 指标，镜像拉取更可控。

### 更新内容

#### 新增

- **运行时指标** — 指标页总览与历史趋势；Bot 列表 / 设置可查看实例指标
- **主机资源** — 本机与远端展示内存、CPU、磁盘（远端经 host-stats / SSH）
- **Desktop 退出后仍可续采** — 配合 ncd-watch 保留 Bot 指标历史（需已部署对应 watch）
- **Docker 镜像源** — 部署时可选择镜像源 / 镜像站优先，减轻拉取失败
- **Docker 拉取可取消** — 拉取任务支持取消；卡死场景可换源重试并给出明确分类提示
- **强制停止反馈** — Docker 相关强制停止操作有更清晰的进度与结果反馈

#### 修复

- 指标轮询不再带动刷新按钮与 Tooltip 抽搐
- 远端指标是否过期改用主机时钟判断，减少误报 stale
- SnowLuma WebUI 端口被占用时自动换口，并按日志重连
- NapCat 正向 / 反向 WebSocket 文案对齐
- 选择基座鲁棒性增强
- 组件与版本检查：按 semver 选最新 Release；强制刷新可绕过查询缓存
- 流式命令支持取消，并在需要时强杀本机 / 远端进程
- Desktop 协议门禁改为应用级 host 单例，避免多入口状态不一致
- Windows 下 QQ 无法下载的情况

#### 说明

- 本版含内部模块拆分与目录整理，**不影响**既有配置与覆盖升级路径
- 发版说明改为仓库内策展文件（`docs/releases/`）；应用内更新说明仍读 GitHub Release 正文
