修复聊天异步串线与机器人启停，并优化发布构建速度。

### 更新内容

#### 聊天异步串线

- 为释放后重挂、文件转发、戳一戳和截图结果增加所属代次校验：连接断开或账号切换后，旧的异步结果不会再落到新的连接上，避免消息发到错误账号/会话、旧发送锁冲掉新发送等情况。
- 窗口交接保留最新导航：从主窗让位聊天窗时只完成本次目标导航，不会为旧页留下回滚；聊天页与调试台的独立窗口探测不再吞掉其他功能变化下的有效导航，窗口状态异常会给出错误提示并允许重试。
- 恢复截图快捷键的卸载清理，避免快捷键在卸载后残留。
- 修正聊天附件读取与发送。

#### 机器人启停与恢复

- 停止请求会取消排队中的重启，但保持当前停止确认代次，已发出的停止仍能按原 revision 正常收口，不会卡在停止中或再次进入启动中。
- 满额恢复时保留已有 Bot：重复恢复时已存在的 Actor 不占新名额，也不会被误报为跳过；接管和自动启动不丢失。
- 修正远端选择、Windows 部署草稿和二维码更新。

#### 历史详情读取

- 调试台历史按 ID 查找改用最新条目语义：同 ID 多行时选择最后一条，回包被预算淘汰后从磁盘补读仍返回同一条记录。
- 历史补读接受合法 JSON 的字段重排、空白和转义，不会因为字面格式不同丢掉全文。
- 修正运行时选择。

#### 说明

- CI 门禁与发布流水线做了一轮性能优化（并行测试分片、缓存命中、发布链接提速），属于内部效率改进，行为不变。
