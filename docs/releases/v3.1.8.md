NapCatQQ Desktop v3.1.8 发布，修复 Webhook 通知测试需要先保存两次才能生效的体验问题。

### 更新内容

#### 修复

- 通知页编辑 Webhook 通道时，点「发送测试」即可用当前正在编辑的配置直接测试，无需先「完成」再「保存设置」。新建通道也能直接测试，不必再走「添加 → 关闭 → 重新编辑」绕一圈。
- 去掉了测试成功提示里「若刚改过配置，请先保存设置」的误导文案；现在报错就是真的配置有问题。

#### 改进

- 「发送测试」按钮从密钥字段下方移到编辑弹窗底部，放在取消与添加/完成之间，更容易发现。
