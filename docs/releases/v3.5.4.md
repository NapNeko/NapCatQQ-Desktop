本次更新跟进应用端框架的上游配置，补齐设置入口，并改善配置保存、校验与旧实例兼容性。

### 更新内容

#### 新增

- **AstrBot** — 增加按上游配置分组的高级设置，支持联网搜索、文件处理、日志等设置，并兼容新版运行器配置。
- **MaiBot** — 同步最新配置，补充 Agent、联网服务、图像记忆、模型类型与分时价格等设置。
- **TRSS-Yunzai** — 补齐九份配置的表单，加入 HTTPS、Milky、Satori、数据库及 Redis 用户名等设置。

#### 改进

- **NoneBot2** — 补充请求和会话超时、HTTP 签名、正向连接及驱动扩展设置，兼容 OneBot 专用配置别名。

#### 修复

- **NeoBot** — 修复已有模型参数显示为默认值的问题，补齐可选参数与自定义请求体编辑，并正确提示网页面板配置需要重启。
- **Koishi** — 修复动态表单中部分联合配置的必填项漏校验。
- **配置读写** — 修复环境变量 JSON 转义、大小写与引号处理问题，保留已有自定义字段、注释和旧版配置。
- **配置草稿** — 修复撤销或重新读取后未恢复最新配置的问题，避免切换实例后被迟到的读取结果覆盖。
