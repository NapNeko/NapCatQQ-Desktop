本版正式带来 Linux 桌面支持，补齐本机部署、Docker、原生托盘与高分屏体验，并修复多项协议端和应用端安装问题。

### 更新内容

#### 新增

- **Linux 桌面** — 首次提供 Linux x64 的 deb / AppImage 安装包，支持本机 NapCat / SnowLuma、七种应用端框架、内嵌终端及远端主机管理。
- **本机 Linux Docker** — 支持在本机拉取镜像、创建和管理 NapCat / SnowLuma Bot，补齐 Docker 引擎、镜像架构、端口与容器启动状态校验。
- **界面缩放** — 设置 → 外观新增 100% / 125% / 150% 界面倍率，保存后同步主界面、聊天和调试窗口，重启后保留选择。
- **Linux 原生托盘面板** — 支持 XEmbed 的环境可右键托盘直接打开自绘面板，提供 Bot 操作、账号菜单与未读预览，跟随主题和界面缩放；不支持的环境保留系统菜单入口。面板独立于主界面，轻量模式下打开也无需重建主窗口。

#### 修复

- **Linux 主题切换** — 修复切换主题时 WebKitGTK 可能导致程序崩溃的问题。
- **Linux 本机安装** — 修复 NapCat / SnowLuma / QQ 安装时无法输入 sudo 密码重试的问题，重试保留 SnowLuma Full / Lite 包型；调整本机 QQ 依赖检查，修正 SnowLuma 内置 Node 与运行目录识别，以及本机下载进度误标为远端的问题。
- **MaiBot 安装与端口** — 源码未附带 `uv.lock` 时可继续安装并生成实例锁文件；适配新版 HTTP 监听配置，避免分配端口与实际监听端口不一致。
- **应用端就绪判断** — NoneBot2 / MaiBot 安装失败后不再把残留目录误判为可运行；修复云崽安装和启动子进程未沿用所选 Node / Git / pnpm 工具链的问题。
- **Windows Python 安装** — 遇到 448 错误后重新检查 Python 是否可用，可用时继续安装；仍不可用时提供更换目录和手动安装提示，避免反复进入失败流程。

#### 改进

- **Linux 启动窗口** — 根据显示器可用工作区与系统 DPI 调整初始大小，大屏使用更大的窗口，小屏同步降低最小尺寸；从轻量模式重建主界面时同样生效。
- **窗口圆角与调整大小** — 补齐 Linux / Windows 10 的窗口圆角，增加八方向尺寸拖动热区，改善 Linux 下边缘和角落难以拖动的问题；最大化和全屏时使用直角，Windows 10 圆角兼容模式不保留系统阴影。
- **Linux Dock 图标** — 对齐应用身份、桌面入口与图标资源，修复 Dock 缺少 NCD 图标的问题；开发运行也会自动准备独立图标入口。
- **远端 Linux 部署** — 按目标主机实际架构选择安装产物，完善组件与应用端启动前的运行入口、工具链及端口检查，让安装失败和启动受阻的原因更清楚。

#### 说明

- Linux 当前通过新版安装包手动升级，原生截图暂未提供。Docker 部署支持 NapCat / SnowLuma Bot，应用端框架仍使用原生部署。
