**NapCatQQ Desktop 3.1.12**

Windows 桌面控制台更新（NapCat / SnowLuma 管理）。

### 更新内容

#### 新增

- 增加远端 SnowLuma 重建 WebUI 与 noVNC 连接入口
- 暴露 retry_snowluma_ui 命令以支持手动重建远端 UI 隧道
- 增加远端 SnowLuma UI 隧道重建方法并在路由获取时刷新 Host 会话
- 增加自绘托盘面板、拖拽排序与卡片定高呼吸感排版
- 实现自绘托盘面板与轻量模式彻底释放进程
- 快照列表查询默认按 bot_id 稳定排序

#### 修复

- 托盘面板支持直接展示 Bot 启停失败错误提示
- 托盘面板对齐点击所在显示器工作区并添加越界保护
