新框架一位：NeoBot（纯 Python 实现的 QQ 聊天机器人）正式接入，新建、安装、对接、停止全链路可用。另有重要修复一个：AstrBot 升级 v4.26 后桌面端一直提示「用户名或密码错误」的问题已解决，新旧版本的 AstrBot 现在都能正常代登录。本版不含聊天相关改动（仍在开发中）。

### 更新内容

#### 新增

- **应用端 · NeoBot** — 接入 [NeoBot](https://github.com/SuperQuail/NeoBot)：新建实例一键安装（uv + PyPI `neobot-app`），也可直接导入已有项目（只同步依赖，不动你的脚手架和端口）；OneBot 反向 WS 对接与其他应用端一致；配置页类型化编辑 `data/config.toml` 的适配器段与面板配置，改哪写哪、保留注释
- **NeoBot · 按版本安装** — 新建实例与「重装 / 换版本」时可以从 PyPI 版本清单里挑选版本，不再只能装最新；实例列表卡片与详情页头部会显示已装版本、有新版本时给出提示（版本号按 PEP 440 规则比较，`1.2.1a1`、`1.0.0rc1` 这类预发布版本不会误判新旧）
- **NeoBot · 优雅关闭** — 停止实例（1.2.3 及以上）时先经面板接口请它自行收尾——NeoBot 关闭时要完成记忆总结，可能花几分钟，桌面端最长等待 15 分钟；版本不够或请求未送达再按进程树回收

#### 修复

- **AstrBot · WebUI 代登录** — AstrBot v4.26 起登录接口改为接收明文密码（此前接收 MD5），桌面端仍按旧协议提交，导致 AstrBot 升级后概览、跑着改配置等页面一直提示「用户名或密码错误」，而浏览器里同样的密码能正常登录。现在：v4.28 及以上优先走上游的桌面托管会话，免密码直接登录；密码登录自动适配新旧两种协议，≤ v4.25 的旧核心也照常可用
- **日志** — 支持 loguru 的裸 ISO 时间与竖线等级写法：NeoBot（以及其他用 loguru 的框架）的日志此前整段识别不出时间和等级，现在能正确解析并按等级着色

#### 说明

- AstrBot 的免密代登录在该实例下次由桌面端启动后生效；不重启也不影响使用——桌面端记住的密码会按新协议自动适配
- 由桌面端启动的 AstrBot 实例，其 WebUI 里的「重启 / 更新」入口会关闭（统一由桌面端管理）
- NeoBot 优雅关闭需实例版本 ≥ 1.2.3
- 本版数据路径与既有配置不动；覆盖安装即可
