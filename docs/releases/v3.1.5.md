NapCatQQ Desktop v3.1.5 发布，修复 SnowLuma 有头模式停用后 `node.exe` 残留导致重启多开的问题。

### 更新内容

#### 修复

- 修复本机 SnowLuma 共享 daemon：最后一个 Bot 停用后会正确关闭 `node.exe`，避免再次启动时多开（[#125](https://github.com/NapNeko/NapCatQQ-Desktop/issues/125)）。
- 多 Bot 仍共享同一 daemon；仅全部本机 SL Bot 停用后才结束 node 进程。
- 修正本机协议弹窗取消路径，避免误减 daemon 引用计数。

#### 说明

- 远端 SnowLuma 原本已在引用归零时停止 daemon，本版将本机语义与之对齐。
