配合 Desktop 3.4.4，新增远端同机重登互助。启用后，由远端 ncd-watch 持续处理掉线事件和管理员的二维码刷新请求，Desktop 关闭或断网后也能继续值守。

### 更新内容

- **重登二维码通知** — 账号曾在线且持续掉线后，通过同机其他在线 Bot 私发通知和可用二维码。手动停止、首次等待登录或无法确认账号状态时，不自动发送重登码
- **管理员刷新指令** — 支持回复重登通知「刷新二维码」，或使用 `/ncd 刷新 QQ号或唯一名称` 获取当前码。群内指令需要来自已配置管理员并 @ 互助 Bot，二维码回复仍走私聊
- **避免重复投递** — 保存掉线事件、指令去重与投递结果，投递结果未知时避免立即切换互助 Bot 重复发送。账本不保存二维码，过期二维码也不会追加通知
- **配置与状态查询** — 增加能力查询和重登状态查询，供 Desktop 确认配置是否已加载。没有在线互助方时，可尝试已配置的邮件与 Webhook 通知

### 升级说明

建议先升级 **Desktop 3.4.4**，再从组件管理更新远端 ncd-watch 并同步通知配置。在「设置 → 通知 → OneBot」配置同机互助 Bot、管理员 QQ 号以及「远端掉线后发送重登二维码」。互助方需要通用正向 WebSocket。

SnowLuma 取码仍依赖 QQ 的图形会话和扫码控件；控件或会话不可用时，需要通过 QQ / VNC 处理。刷新指令不会主动重启 QQ。
