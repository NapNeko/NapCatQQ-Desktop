小游戏不复刻、不增加页面入口。第三方插件自行挂载的任意 HTML 页面保留原页面入口，过滤 `/game`、`/games`、`/starship`。其布局与业务无法由 NeoBot 的统一管理 API 推导。

保存继续交由 NeoBot 执行：字符串 revision 原样传回；档案 PUT/DELETE 携带 version；409 回包保留服务器内容，失败不清除草稿。配置、模型、模板、环境变量、插件配置与档案草稿在同一实例详情内切页保留，离开详情释放，不落盘。后台压缩的 task_id 在详情内保留，返回页面后续查。

HTTP 转发固定回环，远端实例通过对应主机的 SSH 隧道访问远端面板，隧道失败不会回落到本机同端口。PUT/DELETE 仅放行档案 item；登录/CSRF token 留在 Rust。管理开关、内部表限制与模型引用检查最终由上游执行。请求重载且未成功时显示警告；仅保存不误报重载失败；需重启的模块由回包列出。登录接口要求 NeoBot 1.2.4a1 及以上，具体管理接口仍以上游版本为准。旧版本缺少接口时提示升级；面板未启动时仍可使用共用原始文件编辑器。

当前上游会话详情是快照与请求历史，没有独立 Mermaid 流程图或漂移检查接口；快照中上游已截断的部分明确标注，完整历史正文在 Desktop 不再截断。上游只支持查看压缩快照，故不增加恢复操作。

验证重点：真实上游契约字段、HTTP 鉴权/CSRF/冲突载荷、配置与档案版本保护、无效草稿阻止保存、跨页草稿、实例缓存隔离、只写密钥、可操作预览。真实 NeoBot 进程联调结果应独立记录，不能用预览测试替代。
