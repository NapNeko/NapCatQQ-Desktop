# README 界面截图

这组图片来自 2026-10-12 的项目浏览器预览（版本元数据 `3.4.3`），使用 `src-ui/core/ipc/mock/` 的演示数据，不代表真实账号或远端环境验证。

| 文件           | 内容                                     |
| :------------- | :--------------------------------------- |
| `chat.png`     | 私聊会话、消息与输入框                   |
| `apps.png`     | 七种框架的应用端实例列表                 |
| `debug.png`    | OneBot `get_login_info` 只读请求与事件流 |
| `terminal.png` | 机器人页面与本机终端面板                 |

更新时运行 `pnpm.cmd run dev`，打开 `http://localhost:1420`，使用 1440 × 900 视口。在「设置 → 外观」选择「方正」圆角风格并保存，再通过界面切换页面、选择演示会话 / 请求后截图，避开启动动画、悬停提示和临时通知。不要使用真实账号数据；界面变化后同时检查根 README 的说明与图片引用。
